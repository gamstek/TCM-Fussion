# 01｜架构总览

同步版本 v4.0｜2026-11-04。运行者可用本页确认 A、B、C 的边界。

```text
原图 → A 五折各自推理 → 逐折 Top-K → 候选映射、去重 → 差异判据
                  ↘ 平均榜 → 旧路由和最终对照报告
原图 / 已有工件 → B 工具 ← C LangGraph 规划 → MCP / 本地注册表
                    ↓ 合法观察与工件 → 原 B 规则 decide → 融合报告
                    ↘ 动作反馈 → 任务内反思卡 → 后续规划
```

| 部件 | 输入 → 输出 |
|---|---|
| 原 A CLI + [适配器](../lib/adapters.py) | 原图与权重 → 平均榜及独立的 `fold_rankings` |
| [候选策略](../lib/candidate_policy.py) | 逐折榜单 → 每折 Top-K、可映射的药材 ID、未映射类别 |
| [证据运行时](../lib/evidence_runtime.py) | B 已有支持、A 候选及判据 → 合法补查和规划摘要 |
| [LangGraph](../lib/react_graph.py) | 证据、动作、预算 → 模型选择、反馈、停止原因 |
| [工作流会话](../lib/workflow_session.py) | 原图及版本化工件 → 阶段动作、来源绑定和证据提交 |

默认每折 K=3。三名是**每折候选数**，实时规划可看预算内的全部合法动作。A 的排名不增加规则分数。规则裁决仍来自 Plan B 的证据。当前首次检测零框的局部补救需要显式 ROI；已有裁图后才可能按失败派生 ROI。详见 [04 工具](04_工具清单.md)。
