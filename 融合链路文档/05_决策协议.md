# 05｜决策协议

同步版本 v6.0｜2026-11-10。主测试配置为 `adaptive_v2 + llm + mcp + active`，默认走 fast 路径。

## 1. ReAct 循环

| 阶段 | 行为 |
|---|---|
| Assess | 规则重评分，读取证据、目标、预算、required coverage、假设，生成合法动作及停止建议 |
| Think | GLM 看逐折候选、判据、最近观察、预算和 coverage，选择当轮短编号或停止 |
| Act | 调 MCP/本地工具，校验结果，提交证据或记录失败，再回到 Assess |

规划器不能直接写证据；A 先验、判据缺口和假设状态都不是显微证据。

## 2. fast 路径的决策边界

默认：

```text
fast_yolo_stage2 = true
```

第一轮 Agent 应优先：

```text
detect_fov_initial（每图）
→ classify_target（YOLO crop）
```

此时不应：

```text
propose_regions
roi_screen / roi_screen_batch
普通 hybrid_scan
```

当某类 required feature 在同一样本的全部视野中均未覆盖时，runtime 为可补查视野提供一次：

```text
hybrid_scan fallback
features = missing_required[:fast_fallback_max_features]
max_locate_calls = fast_fallback_max_locate_calls
```

当前值：

```text
fast_fallback_max_features = 3
fast_fallback_max_locate_calls = 12
feature_scan_tile_policy = full
```

fallback 完成后：

```text
4 tile 有 crop → 合并 → classify 新增 crop
4 tile 全空 → 该 feature 结束，不重试
```

## 3. 候选与 P0

- 每图五折各自 Top-3，映射去重后形成候选兴趣。
- B 规则候选池不被 A 截断；A 只决定重点补查方向。
- `adaptive_v2` 的 P0 缺口只是建议，不是强制路线。
- 模型可以提出、调查、暂停、撤销、恢复假设；状态不是证据。
- 模型可以覆盖软停止建议，但必须记录理由；硬预算、身份、标定、质量和证据版本仍由程序校验。

## 4. required coverage

fast 模式按样本合并各视野的有效分类。同一特征在任一视野检出即可覆盖，逐图缺失仅供审计。样本级字段如下：

```text
required_features
required_all
missing_required
required_useful
```

不是：

```text
只要有一个 feature_id 就算该图覆盖
```

例如：

```text
YOLO 检出 fiber
required = needle_crystal
→ missing_required 仍包含 needle_crystal
→ 仍允许一次 GLM fallback
```

`finish_veto` 在 fast 模式使用 `missing_required`：

```text
missing_required 非空
→ 不允许直接 finish/request_review
→ 先尝试合法 fallback/classify/locate
```

如果 fallback 全空，仍保留：

```text
insufficient_evidence
unknown
```

不把“没扫到”改写成“阴性”。

## 5. 身份完整性门

```text
identity_required crop
+ 尚未分类
+ det_score < 0.8
→ identity_pending
→ 只允许 classify 最高分 crop
→ 清空 stop
→ classify 尝试后才允许继续 locate / 暂停 / review
```

高分：

```text
det_score >= glm_locate_threshold=0.8
→ locate_override
→ 可进入诊断性 IGM/测量
→ 不强制 classify
```

`box_quality=blank` 不再无条件阻断高分 crop；低分 blank 仍阻断 segment。

## 6. classify

`classify_target` 现在：

```text
CNN batch 全部待分类 crop
→ top1_prob >= cnn_threshold、熵低、非 other
   → source=cnn
→ 否则 GLM classify 兜底
```

GLM 是低置信兜底；required crop 的 YOLO 复核只在同类命中时融合，YOLO 未命中时保留 GLM。

## 7. 停止

常见停止码：

```text
no_legal_actions
budget
deadline
planner_request_review
runtime_request_review
override_exhausted
```

停止码不是诊断。正常停止后：

- 固定证据版本；
- 生成 `final_evidence.json`；
- 生成 `final_assessment.json`；
- 生成 `report.md`；
- 保留 `review_required`。

`pilot_empty` / fallback 全空只表示该轮 tile 没找到，不等于目标不存在。

`override_exhausted` 只表示连续覆盖停止建议且没有可重置进展；不是“无目标”。

## 8. 收尾与回退

```text
agent.workflow.final_assessment_llm=true
```

默认预留 finalization 预算、一次文本调用和 30–45 秒。末次调用不发图、不调用 MCP、不新增证据。

如果文本失败、引用非法、证据包超限或硬截止：

```text
→ 程序化 final_assessment
→ 记录 method / model_failure / usage
```

模型倾向不等于原规则确认；`fused_score` 不等于准确率。

## 9. Reflection

- 任务内 Reflection：连续无收益或动作失败时生成结构化提示卡，只调整后续策略；
- 离线 Reflection/LangMem：显式命令生成、回放、验证、发布；
- 任务反思不能修改工件、尺度、判据、权限或资格。
