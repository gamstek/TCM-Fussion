# 05｜决策协议

同步版本 v5.0｜2026-11-08。主测试配置为 `adaptive_v2 + llm + mcp + active`。

## 1. ReAct 循环

| 阶段 | 行为 |
|---|---|
| Assess | 规则重评分，读取证据、目标、预算、覆盖和假设，生成合法动作及停止建议 |
| Think | GLM 看逐折候选、判据、最近观察、预算和覆盖，选择当轮短编号或停止 |
| Act | 调 MCP/本地工具，校验结果，提交证据或记录失败，再回到 Assess |

规划器不能直接写证据；A 先验、判据缺口和假设状态都不是显微证据。

## 2. 候选与 P0

- 每图五折各自 Top-3，映射去重后形成候选兴趣。
- B 规则候选池不被 A 截断；A 只决定重点补查方向。
- `adaptive_v2` 的 P0 缺口只是建议，不是强制路线。
- 模型可以提出、调查、暂停、撤销、恢复假设；状态不是证据。
- 模型可以覆盖软停止建议，但必须记录理由；硬预算、身份、标定、质量和证据版本仍由程序校验。

## 3. 覆盖与 screen

覆盖顺序：

```text
detected_all
→ proposed_all
→ screened_all
→ located_all
```

缺失 screen 且存在多个视野时：

```text
roi_screen_batch
→ screen_concurrency 并发 worker
→ Session 一次提交
```

缺失 locate 时优先补 screen top-k 对；同一 `(image, ROI)` 已经 locate 后不因不同 feature 重做。

## 4. 身份完整性门

这是数据完整性约束，不是 P0 调查路线：

```text
identity_required crop
+ 尚未分类
+ det_score < 0.8
→ identity_pending
→ 只允许 classify 最高分 crop
→ 清空 stop
→ classify 尝试后才允许继续 locate / 暂停 / review
```

classify 失败、不可判或低置信会留下操作记录，不会无限重试；之后可按合法动作继续。

高分：

```text
det_score >= glm_locate_threshold=0.8
→ locate_override
→ 可进入诊断性 IGM/测量
→ 不强制 classify
```

## 5. classify 与类别

`classify_target` 输出：

```text
label / feature_id / confidence / reject / reason
```

GLM 是主分类；required crop 的 YOLO 复核只在同类命中时融合，YOLO 未命中时保留 GLM。分类为：

```text
纤维
花粉粒
图像不可判
```

都不是针晶身份。

## 6. 停止

常见停止码：

```text
no_legal_actions
budget
deadline
planner_request_review
runtime_request_review
override_exhausted
```

停止码不是诊断。正常停止后：

- 固定证据版本；
- 生成 `final_evidence.json`；
- 生成 `final_assessment.json`；
- 生成 `report.md`；
- 保留 `review_required`。

`override_exhausted` 只表示连续覆盖停止建议且没有可重置进展；不是“无目标”。

## 7. 收尾与回退

```text
agent.workflow.final_assessment_llm=true
```

默认预留 finalization 预算、一次文本调用和 30–45 秒。末次调用不发图、不调用 MCP、不新增证据。

如果文本失败、引用非法、证据包超限或硬截止：

```text
→ 程序化 final_assessment
→ 记录 method / model_failure / usage
```

模型倾向不等于原规则确认；`fused_score` 不等于准确率。

## 8. Reflection

- 任务内 Reflection：连续无收益或动作失败时生成结构化提示卡，只调整后续策略；
- 离线 Reflection/LangMem：显式命令生成、回放、验证、发布；
- 任务反思不能修改工件、尺度、判据、权限或资格。
