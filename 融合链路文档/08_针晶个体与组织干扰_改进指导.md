# 08｜针晶个体识别与组织干扰：后续修改指导

版本 v2.0｜2026-11-10｜用于指导后续修改，不是已实现功能，也不是线上效果承诺。

## 0. 先给结论

当前默认路线是 **fast 候选 + required feature 兜底**，不再是“每图全量 propose/screen”：

```text
第一层：YOLO 框全部保留 + CNN stage2 批量分类
第二层：只对 missing required feature 做一次 GLM fallback
第三层：fallback 用 full 4 tile 并发；全空即弃，不无限重试
第四层：mask 后的实例拆分 / 测量仍按原质量门
```

三个约束必须保留：

```text
1. det_score >= 0.8 的原有 mask/measure 路径不改；
2. 不因旁路 audit 判为纤维/组织而阻断高分测量；
3. 不把参考标签、测试图真值或人工答案注入在线规划。
```

如果只能做一件事：

> **先把 missing required feature 的 fallback 做对：只补缺失 feature，不回到 192 ROI screen。**

如果只能做两件事：

> **再加 full 4 tile 的受控并发和全空即弃，避免空 tile 无限占用。**

如果要做完整方案：

> **最后再训练专用针晶/干扰实例分割模型，或做更细的 tile 预筛；不能把 fallback 空结果当成阴性。**

## 0.1 路线分级总表

| 级别 | 修改内容 | 复杂度 | 预期收益 | 风险 | 先决条件 |
|---|---|---|---|---|---|
| Level 0 | 审计字段、实例统计、可观测性 | 低 | 低（但为后续验收必需） | 低 | 无 |
| Level 1 | 正/负示例、required-feature fallback、旁路 audit | 低–中 | 中–高 | 中 | 少量正负示例；不改高分路径 |
| Level 2 | mask 骨架/旋转框实例拆分、单根测量 | 中 | 高 | 中 | 现有 mask；实例级验收 |
| Level 3 | 域内 YOLOv8-seg 或 A2B-IS 风格模型 | 高 | 最高 | 高 | 实例标注、训练资源、域内测试 |
| Level 4 | Agent 工具编排、参考检索、记忆 | 高 | 取决于 Level 1–3 | 中–高 | 前三层稳定；审核后的参考库 |

收益是**研究假设和预期**，不是已验收结果。建议严格按 Level 0→1→2→3→4 推进。

5. 高分路径不分类，这是有意的约束，但也是假阳性风险敞口。

### 2.1 CountGD++：正负提示与外部示例

论文：[CountGD++: Generalized Prompting for Open-World Counting](https://arxiv.org/abs/2512.23351)

#### 问题

相似对象混在一起时，只描述“要什么”不够，还要描述“不要什么”。论文明确把“视觉相似对象难以区分”列为主要限制。

#### 方法细节

```text
正文本 t+
正视觉示例 B+
负文本 t−
负视觉示例 B−
外部示例（可来自输入图之外）
伪示例（pseudo-exemplars）
```

架构基于 CountGD-Box / Grounding DINO：

- Swin Transformer 图像编码器；
- BERT 文本编码器；
- 正/负示例经 RoIAlign 取特征；
- 正示例与正文本做 self-attention，负示例与负文本做 self-attention；
- 正负提示之间不互相注意，避免无关类别干扰；
- object query 同时与正、负提示计算相似度；
- 过滤条件：

```text
max(Sig(qᵀP+)) > σ
且
max(qᵀP+) > max(qᵀP−)
```

- 正示例和负示例可以来自输入图，也可以来自外部图；
- 伪示例从第一轮高分框中选 top-N，再回灌；
- 论文对伪示例还区分正、负伪示例。

#### 数据与实验

- 训练：FSC-147，额外加入合成 mosaic 图；
- 测试：FSCD-147、PrACo、血细胞、水果、ShanghaiTech、晶体视频等；
- 置信度阈值：

```text
σ = 0.23
```

- FSCD-147 纯文本：

```text
MAE 16.55 → 10.29（+pseudo）
     → 8.39（+pseudo+synthetic）
AP 33.01 → 37.78 → 38.93
```

- 多类数据（血细胞/水果）使用 **每类 1 个内部或外部视觉示例 + 其他类作为负文本**；
- FSCD-147 文本模式使用 **1 个 synthetic exemplar + 3 个 pseudo-exemplars**；
- 晶体视频每帧第一遍使用上一帧 top-10 pseudo-exemplars，第二遍使用当前帧 top-10；
- 伪示例只在满足置信度阈值且更接近正提示（或负提示）的框中选取，不随便取最高分。

- PrACo 负标签测试：

```text
NMN 0.88 → 0.07
PCCN 62.86 → 97.99
```

- 血细胞加入正负示例：

```text
MAE 11.56 → 1.73
AP 0.27 → 0.46
```

- 晶体视频伪示例：

```text
MAE 69.1 → 10
```

#### 对本项目的可迁移点

```text
正示例：单根针晶、成簇中可辨单根、不同背景/染色
负示例：纤维、表皮、花粉、组织、其他结晶
外部示例：来自训练/开发集，不来自当前测试图
负 margin：不要只用一个 needle_score
```

#### 不能直接照搬

- 它是计数/检测，不是单根 mask 分割；
- 针晶是透明/半透明细长体，和论文的血细胞/水果/晶体视频域不同；
- 伪示例如果来自错误组织框，可能强化错误；
- 论文的 confidence 0.23 不能直接搬成当前 workflow 的定位优先级；身份门不由 det_score 绕过。

#### 项目落地方式

不改高分路径，新增**旁路候选审计**：

```text
locate crop
→ CountGD++ 式正/负示例评分
→ needle_score / negative_margin / audit_label
```

对高分 crop 只写审计，不阻断 segment/measure。

### 2.2 A2B-IS：骨架、旋转框、单阶段实例分割

论文：[Skeleton-Guided Sparse Anchors for Rotated Instance Segmentation in Cell Microscopy](https://arxiv.org/abs/2401.09895)

#### 问题

显微图像中对象：

```text
任意朝向
细长/弯曲
粘连/交叉
密集
```

水平框、关键点、网格表示容易把多个实例合并，或边界不准。

#### 方法细节

A2B-IS 是单阶段实例分割：

```text
像素级 mask
+ 旋转框
+ 骨架引导稀疏 anchor
+ Atrous Attention Block
+ SSL teacher-student
```

具体实现：

1. **骨架分支**：预测高斯骨架图，表示实例中心线；
2. **稀疏 anchor**：只在前景骨架像素放一个 3×3 anchor；
3. **分割分支**：预测每类 mask，含背景/重叠通道；
4. **框分支**：预测 5 个偏移量，把 anchor 移动/缩放/旋转为旋转框；
5. **测试阶段**：
   - `argmax(M_seg)` 得到实例 mask；
   - 由骨架 anchor + box offsets 得到旋转框；
   - box score = segmentation map × skeleton map；
   - rotated NMS 去重叠框；
   - 只把重叠区域和同类区域重新分配给框。

训练细节：

- PanNuke 输入 256×256；
- ChromSeg-SSL 输入 512×512；
- Adam，lr 1e-4，指数衰减 0.96；
- 100 epochs；
- batch 2–3；
- 随机翻转/旋转增强；
- 半监督：labeled + unlabeled teacher-student，λ=4；
- 骨架阈值 δ=0.02。

#### 数据与效果

PanNuke：

```text
Mask-RCNN: mAP50 48.3, mPQ 45.2
A2B-IS-L:  mAP50 50.4, mPQ 46.4
```

ChromSeg-SSL：

```text
Mask-RCNN: mAP50 87.5, mPQ 83.8
A2B-IS-L:  mAP50 92.8, mPQ 84.3
```

消融：

- ASA 对 tiny 模型提升明显；
- SSL-IS 进一步提升；
- 二者叠加：PanNuke mAP50 50.7 / mPQ 46.8，ChromSeg mAP50 92.6 / mPQ 85.5（论文报告）。

#### 对本项目的可迁移点

先不训练完整 A2B-IS，先借它的**实例表示**：

```text
mask 骨架化
→ 端点/分支/方向
→ 旋转框
→ 单根拆分
→ 每根 mask
```

这正好补当前：

```text
segment_instance → 一个 mask
measure_instances → 一个长度
```

的缺口。

#### 不能直接照搬

- 论文对象是细胞核/染色体，不是针晶；
- 需要实例级标注；
- 完全重合且无可见边界时，骨架也不能唯一确定单根；
- 旋转框/骨架是表示，不是自动真值。

#### 项目落地方式

先做**实例拆分后处理**：

```text
现有 mask
→ skeleton
→ 端点/分叉
→ 多个实例假设
→ 每根 measure
→ 不可分辨则 merged/unknown
```

不改高分路径，只改变测量粒度。

### 2.3 GenCellAgent：工具编排、参考图、质量反馈

论文：[GenCellAgent: Generalizable, Training-Free Cellular Image Segmentation via Large Language Model Agents](https://arxiv.org/abs/2510.13896)

#### 问题

显微模态和对象变化大，单一分割器失效；新对象没有专用模型；需要工具选择、参考图、质量反馈和记忆。

#### 方法细节

```text
Planning Agent
→ Execution Agent
→ Evaluation Agent
→ feedback / memory / HITL
```

能力：

1. 按图像风格选择专用分割器；
2. 专用工具分数低于阈值时，检索参考图并用 SegGPT 做 in-context adaptation；
3. 无专用工具时：
   - Gemini 3 先把文本描述定位为框；
   - SAM 3 由框生成 mask；
   - 评价反馈后迭代 prompt，最多 5 次；
4. 人类修正写入 memory；
5. 后续任务用参考图/风格相似度检索。

#### 数据与效果

- 7 个细胞分割 benchmark；
- 4,718 张测试图；
- 62 张 anchor 图用于风格相似度路由，不参与评价；
- 工具选择准确率 87.2%；
- 评价器分数阈值设为 40，低于阈值触发 SegGPT 参考适配；
- text-guided 模式最多迭代 5 次，取最高评价 mask；
- Golgi 10 张参考图的渐进实验：GT 参考约 0.35 IoU，人工修正参考约 0.32，自动参考约 0.26；
- 这些数字说明“参考图 + 质量反馈”有潜力，但不能直接搬到针晶；
- 局限性：
  - SAM 3 有生物域差距；
  - Evaluation Agent 受提示措辞影响，可能过度自信；
  - 主要是 semantic segmentation，实例分离不等于已解决；
  - 参考图/描述质量差会带偏。

#### 对本项目的可迁移点

```text
工具选择：needle_scan / candidate_audit / instance_split
参考图：训练/开发集单根针晶
评价：mask/IGM/尺寸质量，而非 LLM 自评分
记忆：只存审核过的参考，不存测试真值
```

#### 不能直接照搬

- 图像风格路由不能替代“针晶 vs 纤维”验证；
- LLM evaluator 不能替代物理 mask 质量；
- 细胞分割工具不是针晶工具；
- 记忆可能过拟合近期样本。

#### 项目落地方式

不要新建平行 Agent；在现有 MCP 工具链上扩展：

```text
needle_scan
candidate_audit
instance_split
reference_lookup
```

由当前 `adaptive_v2` 在冲突、复核、覆盖不足时选择。

### 2.4 B2：YOLOv8-seg 植物纤维/导管基线

论文：[Segmentation and Characterization of Macerated Fibers and Vessels Using Deep Learning](https://arxiv.org/abs/2401.16937)

#### 方法细节

- 1,300 张原始显微图；
- 3,850 张增强图；
- 约 29,861 个对象；
- 1024×1024 输入；
- YOLOv8x-seg；
- 训练时 `overlap_mask=False` 处理重叠 mask；
- 骨架长度 + 距离变换宽度；
- 排除触边对象。

#### 效果

```text
Precision 0.97
Recall 0.90
mAP50 0.94
mAP50-95 0.78
```

#### 失败

- 高密度/拥挤区域仍有假阳性、假阴性；
- 纤维/导管不是针晶；
- 染色/白平衡变化有一定鲁棒性，但不是无限泛化。

#### 项目价值

说明**域内监督实例分割**可行，且骨架测量路径成熟；但不能把纤维模型直接当针晶模型。

### 2.5 CryoAnomaly 与 SAHI：困难负例和局部搜索

#### CryoAnomaly

论文：[CryoAnomaly: Few-Shot Cryo-EM Particle Picking via Anomaly-Guided Hard Negative Suppression](https://arxiv.org/abs/2608.28817)

- 用干净合成数据训练 anomaly detector；
- 真实污染物作为 anomaly；
- SAM 精修 anomaly mask；
- anomaly-guided hard negative suppression loss；
- active learning 选代表性样本。

对本项目：

```text
困难负例银行
```

但必须注意：

```text
稀有针晶也可能被判为 anomaly
```

不能把 anomaly 直接等同于“非目标”。

#### SAHI

论文：[Slicing Aided Hyper Inference and Fine-tuning for Small Object Detection](https://arxiv.org/abs/2202.06934)

- 切图推理/微调，保留局部小目标分辨率；
- 对本项目：全视野固定切图，不依赖初始错误框。

## 3. 建议的总体架构

```text
原图 / N 视野
├─ 现有 detect_fov_initial
├─ 现有 propose_regions
├─ 新增 target-conditioned needle_scan
│    ├─ 正示例：单根针晶、可辨单根
│    ├─ 负示例：纤维/表皮/花粉/组织
│    └─ 输出候选框 + needle_score + negative_margin
│
├─ GLM locate_feature
│    ├─ det_score >= 0.8
│    │    → 原 segment/measure（不变）
│    │    → 旁路 candidate_audit（只写证据）
│    └─ det_score < 0.8
│         → 原 identity_pending / classify
│
├─ segment_instance
│    ├─ 原 mask
│    └─ instance_split
│         ├─ 单根 → 每根 mask/measure
│         └─ 不可分辨 → merged/unknown
│
└─ final_assessment
     ├─ 原证据
     ├─ audit 证据
     └─ instance 统计
```

### 高分路径契约

```text
det_score >= 0.8
→ 不新增 classify 前置
→ 不降低阈值
→ 不因 audit 结果阻断
→ 仍生成 segment/measure
```

新增审计只允许：

```text
记录
解释
触发额外观察
触发复核
```

不允许：

```text
把 audit= fiber 当成强制拒绝
```

这意味着**高分组织框的风险无法被数学消除**；只能通过上游候选生成和下游审计降低概率。

## 4. 分级修改路线

按“简单 → 复杂、可先见效 → 效果显著”排序。

### Level 0：可观测性基线

**复杂度：低｜预期收益：低｜风险：低｜依赖：无**

目的：先能证明后续修改是否有效。

建议：

```text
在 operations 中记录：
  locate 的 source ROI
  candidate_audit 的 label/score/margin
  segment 的 instance_count
  measure 的 instance_id
```

新增字段：

```text
candidate_audit:
  needle_score
  negative_margin
  audit_label
  audit_source

instance_summary:
  n_instances
  merged
  per_instance_length
```

验收：

```text
不改变现有操作数
不改变高分路径
输出仍可读
```

### Level 1：负示例 + 全视野目标扫描

**复杂度：低–中｜预期收益：中–高｜风险：中｜依赖：标注少量正负示例**

这是最值得先做的部分。

#### 1.1 正/负示例包

正例：

```text
单根针晶
成簇中可辨单根
不同方向
不同背景/染色
不同放大倍率
```

负例：

```text
纤维（有连续壁/胞腔）
表皮细胞
花粉粒
其他结晶（非针晶）
纯组织区域
```

要求：

```text
负例必须是本数据集实际误框对象
不能笼统把所有植物组织设为负类
不能使用测试图真值
人工从当前图点出的示例要标记为额外人工提示
```

字段建议：

```json
{
  "id": "needle_pos_001",
  "kind": "positive",
  "label": "needle_crystal",
  "crop": "...",
  "source": "train",
  "visibility": "single_visible",
  "stain": "...",
  "magnification": "...",
  "sha256": "..."
}
```

负例增加：

```json
{
  "kind": "negative",
  "label": "fiber",
  "reason": "continuous wall/lumen",
  "hard_negative": true
}
```

#### 1.2 全视野目标扫描

不要只沿初始错误框放大。

建议实现：

```text
原图
→ 固定 tile（1024 或 512，重叠 10–20%）
→ 每 tile 做正/负示例评分
→ 合并框（NMS）
→ 输出候选和来源 tile
```

可复用：

```text
propose_regions 的切图
roi_screen_batch 的批量
WorkflowSession 的 artifact 版本
```

当前 `propose_regions` 是 6 个 1024 窗口，可保留；新增的是**目标条件评分**，不是替换。

#### 1.3 旁路 candidate_audit

输入：

```text
locate crop
正示例包
负示例包
```

输出：

```text
needle_score
negative_margin
audit_label
reason
```

它不能阻断高分路径。

#### 1.4 论文依据

- CountGD++：正负文本/视觉示例、外部示例、负 margin；
- SAHI：切图保留局部细节；
- CryoAnomaly：困难负例有价值，但不能一刀切。

#### 1.5 验收

```text
纯组织 T3：组织误报下降
T2：有针晶 + 组织同图时，针晶召回不下降
高分路径：det_score>=0.8 的 segment/measure 数量不因 audit 下降
```

---

### Level 2：mask 单根实例拆分

**复杂度：中｜预期收益：高｜风险：中｜依赖：已有 mask + 实例级验收**

#### 2.1 输入

```text
现有 segment_instance 的 mask
原 crop
尺度 px_per_um
```

#### 2.2 处理

```text
二值 mask
→ skeleton
→ 端点/分叉
→ 连通分量
→ 方向/主路径
→ 旋转框
→ 实例拆分
```

实现细节：

1. `cv2.ximgproc.thinning` 或 skeletonize；
2. 端点 = 骨架邻域 1 个像素；
3. 分叉 = 邻域 ≥3；
4. 每个连通分量先作为一个候选；
5. 分叉区域按主方向/最短路径拆分；
6. 对每个候选生成 mask；
7. 用距离变换计算宽度；
8. 用骨架主路径计算长度；
9. 触边对象可标记，不直接测量；
10. 不能拆分时：

```text
instance_status = merged
measurement = unknown
```

#### 2.3 与测量关系

```text
高分路径仍然 measure
但输出：
  n_instances
  per_instance_length
  per_instance_width
  merged/unknown
```

不把整簇长度当单根长度。

#### 2.4 论文依据

- A2B-IS：骨架、旋转框、实例 mask；
- B2：骨架长度 + 距离变换宽度 + 触边排除；
- 但 A2B-IS 是学习模型，本阶段先做后处理，低风险。

#### 2.5 验收

```text
T4 粘连/成簇：
  merge 错误下降
  split 错误不上升
单根长度/宽度可复现
不可分辨样本保留 unknown
```

### Level 3：域内针晶/干扰实例模型

**复杂度：高｜预期收益：最高｜风险：高｜依赖：实例级标注 + 训练资源**

#### 3.1 方案 A：YOLOv8-seg

参考 B2：

```text
输入 1024×1024
类别：needle_crystal / fiber / epidermis / pollen / other_crystal / tissue
overlap_mask=False
实例 mask
骨架长度/宽度
```

优点：

- 工程成熟；
- 可直接输出实例 mask；
- 与现有 YOLO worker 接近。

缺点：

- 需要针晶实例标注；
- 半透明、粘连、遮挡仍是难点；
- 不能保证单根。

#### 3.2 方案 B：A2B-IS 风格

```text
骨架引导 anchor
旋转框
mask + skeleton + box 三头
rotated NMS
```

优点：

- 更贴近细长、任意方向、粘连对象；
- 实例表示比水平框好。

缺点：

- 需要训练和域适配；
- 需要实例标注；
- 复杂度和维护成本高。

#### 3.3 数据选择

训练集：

```text
单根针晶
成簇中可辨单根
不同方向/背景/染色
```

负例：

```text
纤维
表皮
花粉
其他结晶
组织
```

切分：

```text
按物理样品/视野分组
不能同一图多个 crop 跨训练/测试
测试集不参与示例库
```

#### 3.4 与高分路径的关系

专用模型输出：

```text
needle_evidence
instance mask
```

可以：

```text
旁路审计
作为额外候选
作为复核依据
```

但不在本阶段改变：

```text
det_score >= 0.8 直接 mask/measure
```

参考 GenCellAgent，但只吸收：

触发条件：

```text

单根/多根不确定

```

评价器使用：

```text

骨架/实例一致性
标定
尺寸合理性
```

不是单一 LLM 分数。

### 6.6 最小代码落地拆解

建议按下面顺序改，避免一次引入模型、Agent 和证据链三件事。

#### Step 1：审计数据结构

新增只读/旁路工件：

```text

```

`candidate_audit` 建议字段：

```json
{
  "crop_id": "...",
  "needle_score": 0.0,
  "negative_margin": 0.0,
  "audit_label": "needle_crystal|fiber|epidermis|pollen|unknown",
  "reason": "...",

  "non_blocking": true

```

要求：

```text
audit 失败只记录 error，不阻断原有 locate/segment/measure

```

#### Step 2：候选审计接入

最安全的位置是 `locate_feature` 成功后：

```text

```

不是：

```text

→ audit

```

#### Step 3：全视野扫描

先复用现有切图/批量基础设施：

```text

roi_screen_batch 的 worker 并发
```

新增的是：

```text
目标条件评分

负 margin
```

如果暂时没有新模型，可先用 GLM 对每个 tile 做“针晶/纤维/组织”三选一，输出结构化 JSON；这比新增训练模型简单，但成本更高。

#### Step 4：实例拆分

先做**离线后处理**：

```text
读取已有 mask
→ skeleton
→ split
→ 输出 instances_split.json
→ 人工/离线对照
```

不要一开始就改 `measure_instances` 的默认行为。

#### Step 5：接入测量

确认实例拆分稳定后，再加：

```text

```

保留：

```text

```

这样高分路径可以继续按原逻辑运行；拆分结果作为新证据/新测量。

### 6.7 必测断言

```text
1. det_score >= 0.8 + audit=fiber
   → 仍调用 segment/measure
2. det_score >= 0.8 + audit 服务失败
   → 不阻断原始测量
3. det_score < 0.8 + audit=needle
   → 不绕过 identity_pending/classify
4. audit 结果不进入 A 候选扩展
5. 示例库不包含测试图 hash
6. instance_split 的 merged/unknown 不被写成单根尺寸
```

第 1 条是当前设计约束的回归测试，不能被后续优化删掉。

### 6.8 当前已落地的部分

截至 2026-11-08，本次实现只完成了低风险的**旁路基础**：

```text
needle_positive_hint / needle_negative_hint
→ 附加到 roi_screen / locate_feature / classify_target 提示
→ 不改变 det_score 阈值

feature_audit
→ workflow 结束后读取已有 crop/classification/mask
→ 输出 feature_audit/feature_audit.json
→ 标注 candidate 状态、negative_margin、实例拆分
→ 不参与 rule decide，不阻断原测量

needle_scan
→ 针晶兼容名
→ 底层 feature_scan 按 feature_id 泛化
→ 按 feature_scan_tile_size / overlap 分块
→ 每 tile 用带 profile 提示的 locate worker
→ 合并候选 crop
→ 默认关闭，避免不必要的高成本调用

feature_scan / feature_profiles
→ 以 feature_taxonomy.json 为默认全集
→ 配置只覆盖需要区分的特征 profile
→ 针晶负例只属于 needle_crystal，不污染其他特征

instance_split
→ 纯本地 connected components + Zhang-Suen skeleton
→ 统计 endpoints/branches/length_px/width_px
→ merged 标记
→ 写入 audit 目录，不改原 mask
```

**尚未实现**：

```text
完整的正负示例图片库（当前只有文本 profile）
candidate_audit 作为 planner 可主动调用的工具
instance_split 直接替换/增强 measure_instances
域内 YOLOv8-seg / A2B-IS 模型
Agent 参考检索与记忆
```

因此不能把当前实现称为“三层完整上线”；它当前是：

```text
特征 profile（taxonomy 默认 + 针晶 override）
+ 可选的全视野 feature_scan（needle_scan 兼容别名）
+ 旁路 feature_audit
+ 实例拆分诊断
```

其中 `feature_scan` 已具备真正的全视野分块执行路径；当前模板改用 `hybrid_scan`，并发执行 YOLO 初检与 A 候选特征的 GLM tile 扫描，两套 crop 由一次 accept 写入同一 evidence version，tile 上限 4 时在完整网格上均匀取点。`feature_scan_features` 为空，特征来自 A 候选的 required recovery features；不再保留针晶静态扫描入口。

### 6.9 基于 P0 test 错误归因的负例特征

新增：

```text
config/negative_feature_bank.json
```

它不是“把所有组织都当负类”，而是 `target-conditioned` 的负例特征库：

```text
needle_crystal：
  hard = fiber / epidermis / vessel / stone_cell / secretory_tissue
  soft = cluster_crystal / single_crystal / pollen_grain
  excluded = starch_grain
```

数据依据：

```text
漏检 43.4%，类别混淆仅 4.3%
79% 的混淆在纤维/表皮/导管/石细胞/分泌组织簇内
淀粉粒漏检 79.7%，但类别混淆 0
花粉粒漏检 4.5%，类别混淆 0
```

因此：

```text
1. 淀粉粒不进入针晶硬负例；它的问题是漏检/标注单元，不是针晶混淆；
2. 组织簇负例只用于 candidate_audit / 提示，不做全局类别抑制；
3. 负例不能替代召回修复和标注单元统一。
```

配置 `feature_profiles` 已为 needle、fiber、epidermis、vessel、stone、secretory 添加对应的困难负例描述；`feature_scan` 只有在启用时才使用这些 profile。

仍然缺少的是：

```text
实际的负例 crop 图片和来源/hash/审核状态
```

当前是**特征描述库**，不是完整图片示例库。

### 6.11 CNN 特征分类器接入

当前 `classify_target` 固定为：

```text
CNN batch 初判
→ 高置信且非 other：source=cnn
→ 否则 GLM 兜底
```

```text
首次 classify
→ 对全部待分类 crop 做一次 ResNet18 batch（不再只限 identity_required）
→ top1_prob>=0.75、entropy<=0.8、top1!=other 且 feature 合法
   → 直接写 source=cnn
→ 否则 GLM classify_target 兜底
```

边界：

```text
1. CNN 只判 14 类特征，不判药材；
2. 不替代 locate，不解决 YOLO 漏检；
3. 没有 unreadable 类，低置信/other 回退 GLM；
4. required crop 的 GLM 结果仍做 YOLO crop 复核；
5. 权重在 分类器设计权重与CNN权重/，用 .venv/yolo 运行。
```

### 6.12 框质量与 YOLO/GLM 合并

当前每个 crop 记录：

```text
box_source = yolo | glm
box_quality = usable | low_detail | blank | tiny | invalid
box_quality_flags = blank/low_detail/tiny/border/large
box_quality_metrics = std/edge/size/area_ratio
```

策略刻意宽松：

```text
1. blank 只阻断低分 segment；`det_score>=0.8` 高分即使 blank 也保留后续路线；
2. low_detail 只标记，不丢框；默认不进入 segment，只有 `det_score>=0.8` 可绕过；
3. 同一特征 GLM 框与 YOLO 框 IoU>=0.5 时保留 YOLO，跳过重复 GLM；
4. blank/low_detail 允许一次 loose_box 重定位（locate:roi:boxq:*）；
5. 不在单图内强制至少一个框，也不把“框数量”当目标。
```

这解决的是“框内空白/重复框”，不是替代 locate 或测量。

### 6.16 locate 最小观察尺寸

```text
locate_min_roi_side = 256
locate_min_box_side = 90
```

- ROI 小于 256 px 时围绕中心扩展，再交给 GLM；
- tight box 小于 90 px 时围绕中心扩展，保留原 `source_tight_bbox`；
- 不直接拒绝小目标，但避免 50–70 px 框在图内被放大成失焦 crop；
- 高分 `det_score>=0.8` 仍绕过质量门；低分 blank 仍阻断 segment。

空目标必须返回 `{"objects":[]}`，不伪造 crop。

### 6.15 fast_yolo_stage2

`fast_yolo_stage2=true` 时：

```text
每图先 detect_fov_initial（YOLO）
→ 所有 YOLO crop 全部保留
→ classify_target 的 CNN batch 全部分类
→ 在每图 crop 尚未全部分类前，不创建 propose_regions / roi_screen / hybrid_scan
→ 同一样本的整组视野仍缺少某个 required feature
   → 仅创建一次 hybrid_scan 兜底，最多 fast_fallback_max_features 个缺失 required feature
```

优先级：

```text
YOLO 框全部保留
CNN 高置信直接采用
CNN 低置信/other 回退 GLM classify
GLM 只补缺失视野
```

不改变：

```text
identity/quality/calibration 门
segment/measure 条件
证据版本和预算
```

### 6.17 GLM fallback tile policy

```json
"feature_scan_tile_policy": "full",
"fast_fallback_max_locate_calls": 6
```

```text
full：一次把 4 个 tile 全部并发提交
→ 任一找到 crop 就合并继续
→ 全部为空则立即返回空，不重试

prescreen：先扫纹理最强 pilot
→ pilot 空即停止该 feature
```

`fast_fallback_max_locate_calls` 限制一次 hybrid 兜底的总 locate 次数，避免 2 feature × 4 tile 无上限扩散。

### 6.18 检测与自动标定解耦

`detect_fov_initial` 先完成 YOLO；自动 scalebar 失败只置：

```text
px_per_um = None
```

不丢弃 `boxes.json` / crop，不再把整个 detect 操作标记失败。后续可显式：

```text
calibrate_fov
```

真实失败 `UPSTREAM_NETWORK_FAILED`（RemoteDisconnected/URLError）应保留为 service failure，不能当成“无目标”。

### 6.13 覆盖交给 Agent，而不是硬编码动作顺序

`agent_driven_coverage=true` 时：

```text
coverage / required_features / missing_required / remaining_budget / remaining_seconds
→ 注入 planner context
→ planner 自行选择 scan / classify / locate / measure / finish
→ runtime 只校验合法性、证据版本、预算、时间和 finish_veto
→ planner 失效时才用 required coverage 做兜底
```

fast 模式的 finish_veto 使用 `missing_required`，不是任意 `missing_useful`；检出 fiber 不能代表 needle_crystal 已覆盖。

不再由运行时强制：

```text
先 detect → 再 propose → 再 screen → 再 locate → 再 classify
```

硬约束仍保留：

```text
1. 每步只能提交一个合法 action；
2. 不能跳过身份/质量/标定/证据版本；
3. 不能超过 max_api_calls / max_seconds / max_resource_units；
4. 没有有效证据时 finish_veto 仍生效。
```

## 7. 评测计划

### 7.1 测试桶

| 桶 | 内容 | 重点 |
|---|---|---|
| T1 | 有针晶、无明显组织 | 基础召回 |
| T2 | 有针晶 + 组织同图 | 干扰下召回 |
| T3 | 仅组织、无针晶 | 组织误报 |
| T4 | 粘连/交叉/成簇 | 单根分离 |
| T5 | 模糊/弱边界/不可分辨 | 是否保留 unknown |

### 7.2 指标

```text
针晶 Recall / Precision
固定组织假阳性水平下的针晶召回
T3 组织误报率
实例 merge / split 错误
单根数量误差
mask/IGM 合格率
measurement yield
高分路径不变性
```

### 7.3 消融

```text
A 当前基线
B + 负示例候选审计
C + 全视野 needle_scan
D + instance_split
E + 域内专用模型
F + Agent 调度
```

每一级只加一个变量；不要一次全开。

### 7.4 高分路径验收

必须写一条独立断言/检查：

```text
对每个 det_score >= 0.8 且 QA 允许的 crop：
  新逻辑不得因为 audit 判纤维/组织而取消 segment/measure
```

否则就违反当前约束。

## 8. 风险与停止条件

| 风险 | 缓解 |
|---|---|
| 示例泄漏测试集 | 示例库只来自 train/dev，记录 sha256 和来源 |
| 负例过度抑制 | 只收困难负例，不用所有组织；保留 unknown |
| 伪示例强化错误 | 初始错误框不回灌；人工审核 top-N |
| 成簇 mask 强行拆分 | 无可见边界时输出 merged/unknown |
| 专用模型域偏移 | 按样品分组评测，保留旧基线 |
| Agent 评价器过度自信 | 用 mask/IGM/尺寸指标，不用 LLM 自评分 |
| 高分组织框仍被测量 | 接受为已知风险；用上游扫描和旁路审计降低概率 |

停止条件：

```text
Level 1 在 T2 上针晶召回下降 > 可接受阈值
Level 2 merge/split 错误上升
Level 3 域内验证无增益
任何级别导致高分路径测量数无故下降
```

## 9. 推荐执行顺序

```text
第 1 步：Level 0 可观测性
第 2 步：Level 1 负示例 + 全视野扫描
第 3 步：Level 1 旁路 audit
第 4 步：Level 2 骨架实例拆分
第 5 步：Level 2 实例级测量
第 6 步：Level 3 专用 YOLOv8-seg / A2B-IS 风格模型
第 7 步：Level 4 Agent/参考记忆
```

每一级都必须：

```text
不改高分直通
不注入参考真值
有独立测试桶
有前后对比
有 artifacts
```

## 10. 一句话指导

> **先用正/负示例和全视野扫描把“组织候选”挡在 GLM 高分框之外；再用骨架/旋转实例拆分把“成簇针晶”拆成可见单根；最后才训练专用模型和 Agent。高分直通逻辑保持不变，新增内容只做候选生成、实例表示和非阻断审计。**
