# 调查自主性与无收益收尾

LOW-DETAIL-001（2026-11-17）补充：low_detail统一作为质量提示，不一票否决分割；同类别身份确认后可供模型选择segment。灰度/边缘标记和指标保留，blank继续阻断，mask/标定/量纲资格不放松。旧low_detail阻断开关已删除；历史运行仅作审计，不改写。

版本 v1.1｜2026-11-17｜ADVISORY-001 / LOW-DETAIL-001。按用户补充授权实施；覆盖方案10中旧的自动 required 调查顺序，不代表 D3 Reflection/DAG 全部完成。

## 1. 为什么不是简单删除停止上限

既有实验出现过反复选择 finish、程序拒绝、模型再次规划的循环，增加规划请求与时间。这条教训保留。

本次区分：**调查方向由模型决定；事实和结论资格由程序校验；连续无进展由程序有界收尾。** 不再把“两次不同意建议”直接等同失败，也不允许无限继续。

## 2. 当前分工

| 保持硬校验 | 改为建议或模型选择 |
|---|---|
| 注册工具、参数schema、来源与坐标映射 | 优先查哪个候选、哪个视野、哪个已有实例 |
| crop身份与分割/测量前置条件 | 先分类、补查、分割还是读取已有证据 |
| 标定、QA量纲资格、原规则和最终引用授权 | required/supporting/其他候选未查完时是否继续 |
| 总时间、请求/资源池、步骤上限及既有工具限额 | 建议停止与无收益前的调查取舍 |
| 同输入同方法去重、服务失败不当阴性 | 不因某特征已有测量就自动隐藏另一合法实例 |

仍默认由 YOLO 做首次显微特征出框，GLM 原图存在性观察不必等待全部视野初检完成。定位/分割等实际工具前置条件保留。

## 3. 自动执行边界

`adaptive_v2 + llm/scripted` 不再由 auto_prepare 抢先选择 CNN batch、top required 实例或场景观察；旧覆盖开关不能把其他合法动作隐藏。auto_prepare_stage 和 auto_required_measurement 仅供读取历史配置。

保留 `auto_measure_after_segment=true`：模型选定具体分割对象后，若原有 QA、身份和标定允许，可自动执行同一对象的测量。这是已授权对象的后续处理，不自动替模型选择另一个药材或实例。原 heuristic/v1 路径未改写为本政策。

模型仍从受信合法集合选动作，没有新增自由ROI、任意提示参数、任意代码执行或取消所有配额的接口。

## 4. 防止重复 stop

```text
模型选择 review → 立即结束调查并生成已有证据报告
模型选择 finish
  ├─ 具备原规则/场景授权 → finish
  └─ 不具备确认资格 → 同轮投影为 review，记录阻塞原因
                             不再次付费询问同一个停止问题
```

review不再被停止冷却隐藏。停止提案附带无效假设更新时，只拒绝该更新，不拒绝结束调查。规划失败/预算不足直接程序化复核，不偷偷挑第一个工具接管调查。

停止执行不等于获得药材确认；最终冻结证据、原 `decide()`、引用资格和报告回退均保留。

## 5. 防止无意义继续

保留原 no_gain_limit（1或2）。达到阈值时优先建议 review，即使还有 supporting 或竞争候选未查，也不把“有缺口”永久解释成必须继续。

模型可继续。每次执行后本地比较调查指纹：

- 判据状态、有效局部存在/未见观察。
- 已检查的新视野、可信标定。
- 经验证的身份、可用mask及允许的测量用途。
- 不把文件改名、哈希变化、同类实例数量累加或切换假设单独算进展。

取得实际新进展则清零宽限计数；**连续两次违背停止建议继续执行，仍无新进展**，以 `no_progress_after_advice` 直接收尾。返回已见过的调查状态也不能伪装成新进展。计数、指纹保留在本地状态，不新增一次“判断有无收益”的模型调用。

这不是完整的信息增益评估：只读查询可能帮助模型理解已有证据，但不会被自动视为新增物理证据；连续只读也受该上限约束。更细的策略收益与Reflection补丁仍属后续工作。

## 7. 效益与限制

减少重复停止请求有机制验证，但未调用真实视觉API，不声称总token/费用/时延下降。取消强制自动调查会增加部分正常步骤的规划次数；同对象自动测量仍减少机械调用。实际净收益须用新任务、同输入/预算对照。

不修改模型权重、原图、历史运行和跨阶段物理契约；不声称完成自进化。项目根无Git，TCM_Fusion既有修改重叠，本批不夹带提交。
