# 04｜工具清单

同步版本 v5.0｜2026-11-08。技能描述指导选法；ToolSpec 与运行时约束授权、参数、目标、预算和结果校验。

## 1. 工具分层

| 层 | 工具 | 作用 |
|---|---|---|
| 只读 | `read_evidence`、`list_features`、`query_criteria`、`read_scale`、`list_fovs`、`criteria_diff`、`list_artifacts`、`read_artifact_status`、`read_quality` | 查已有证据、判据、标定和 QA；不新增视觉证据 |
| 全图检测 | `detect_fov_initial` | YOLO 全视野特征检测 |
| 区域检测 | `detect_region` | 已有 ROI/crop 的局部 YOLO |
| 标定 | `calibrate_fov` | 生成 `px_per_um` 尺度 |
| ROI 提议 | `propose_regions` | 本地 6 ROI 网格和线纹理分，不调用模型 |
| 筛选 | `roi_screen` | 单视野 GLM contact-sheet 排名，不返回框 |
| 批量筛选 | `roi_screen_batch` | 多视野并发 screen，一次提交多个 screen artifacts |
| 定向定位 | `locate_feature` | GLM 在 ROI 中找指定特征框 |
| 身份复核 | `classify_target` | GLM 对 crop 做类别复核；required crop 可加 YOLO crop 复核 |
| 分割 | `segment_instance` | 生成 mask / IGM |
| 测量 | `measure_instances` | 从合格 mask 和尺度生成物理尺寸 |

`roi_screen_batch` 是当前唯一批量视觉工具；`classify_target` 仍是单 crop 串行。

## 2. 类别来源

```text
Plan A → 药材种类（龙胆/麦冬/知母...）
YOLO → 显微特征类别（表皮细胞/分泌组织/草酸钙针晶...）
GLM locate → 指定特征候选框
GLM classify → crop 的身份类别
```

YOLO 不输出药材结论；classify 的最终标签以 GLM 为主，YOLO 只做辅助复核。

## 3. 前置条件

| 工具 | 前置 |
|---|---|
| `detect_fov_initial` | 原图已绑定 |
| `detect_region` | 合法 ROI 或 crop |
| `calibrate_fov` | 原图/标尺可用 |
| `propose_regions` | 原图/检测工件 |
| `roi_screen` | 区域提议完成 |
| `roi_screen_batch` | 多个视野区域提议完成，且缺失 screen |
| `locate_feature` | screen top-k、目标 ROI |
| `classify_target` | `identity_required` 合法 crop |
| `segment_instance` | crop 身份满足、尺度可用 |
| `measure_instances` | 合格 mask、标定、用途资格 |

## 4. 身份门与批量

存在未分类低分 `identity_required` crop 时：

```text
identity_pending
→ 强制 classify 最高 det_score crop
→ 再继续其他动作
```

`det_score >= 0.8` 走 `locate_override`，不强制 classify。

`roi_screen_batch`：

```text
screen_concurrency=3
worker 并发
Session 一次 accept
```

批量 screen 结果仍是每个视野独立的 `screen` artifact。
