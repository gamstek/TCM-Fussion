# 04｜工具清单

同步版本 v4.0｜2026-11-04。技能描述指导选法，ToolSpec 与运行时约束授权、参数、目标、预算及结果校验。

| 层 | 已有工具 | 前置与结果 |
|---|---|---|
| 只读 | `read_evidence`、`list_features`、`query_criteria`、`read_scale`、`list_fovs`、`criteria_diff`、`list_artifacts`、`read_artifact_status` | 查证据、候选判据和已注册工件；只读结果不新增视觉证据 |
| 用途 QA | `read_quality` | `purpose_v1` 下读取评估原因和用途资格 |
| 视觉观察 | `presence_check`、`scene_check` | 绑定图像；存在性限合法 required P1/C，场景由强制条件触发 |
| 定位与标定 | `detect_fov_initial`、`detect_region`、`calibrate_fov` | 首检从原图；局部重检需合法 ROI；标定生成尺度 |
| 实例 | `segment_instance`、`measure_instances`、`classify_target` | 分割需合法 crop 及当前调度要求的尺度；测量需合格 mask；类别复核按特征冲突开放 |

工具以注册动作 ID 或匹配的受信参数执行。人工框仅用于独立诊断或事后验收。首次零框且未配置 ROI 时，当前实现不会自动给出任意局部框；已有 crop 的部分空间失败可以派生 ROI。工具预算分类及参数以[注册表](../lib/tool_registry.py)和[工作流](../lib/workflow_runtime.py)为准。
