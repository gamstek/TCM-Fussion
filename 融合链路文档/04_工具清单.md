# 04｜工具清单

同步版本 v6.0｜2026-11-10。技能描述指导选法；ToolSpec 与运行时约束授权、参数、目标、预算和结果校验。

## 1. 工具分层

| 层 | 工具 | 作用 |
|---|---|---|
| 只读 | `read_evidence`、`list_features`、`query_criteria`、`read_scale`、`list_fovs`、`criteria_diff`、`list_artifacts`、`read_artifact_status`、`read_quality` | 查已有证据、判据、标定和 QA；不新增视觉证据 |
| 全图检测 | `detect_fov_initial` | YOLO 全视野特征检测；标定失败只置空尺度，不丢框 |
| 区域检测 | `detect_region` | 已有 ROI/crop 的局部 YOLO |
| 标定 | `calibrate_fov` | 生成 `px_per_um` 尺度 |
| ROI 提议 | `propose_regions` | 本地 ROI 网格和线纹理分；fast 模式默认不跑 |
| 筛选 | `roi_screen` | 单视野 GLM contact-sheet 排名；fast 默认不跑 |
| 批量筛选 | `roi_screen_batch` | 多视野并发 screen，一次提交；fast 默认不跑 |
| 全视野扫描 | `needle_scan` | 针晶兼容名；按 tile 调用目标条件 locate |
| 通用扫描 | `feature_scan` | 按 feature 做 tile 扫描；支持 `full` / `prescreen` |
| 混合扫描 | `hybrid_scan` | 并发 YOLO + 多特征 GLM；fast 仅 missing required fallback |
| 定向定位 | `locate_feature` | GLM 在 ROI 中找指定特征框 |
| 图片示例审计 | `image_exemplar_audit` | 读取 14 类示例库，旁路审计；不阻断 |
| 身份复核 | `classify_target` | CNN batch 初判；高置信直接采用，否则 GLM 兜底；required crop 可加 YOLO crop 复核 |
| 分割 | `segment_instance` | 生成 mask / IGM |
| 测量 | `measure_instances` | 从合格 mask 和尺度生成物理尺寸 |

`roi_screen_batch` 是批量视觉工具；`classify_target` 对外仍是单 crop 动作，但首次调用会对全部待分类 crop 做 CNN batch 缓存。

## 2. fast 模式实际工具顺序

```text
detect_fov_initial
→ classify_target（全部 YOLO crop）
→ 若 required feature 齐全：
     calibrate_fov
     → segment_instance
     → measure_instances
→ 若缺 required feature：
     hybrid_scan fallback（一次）
     → classify_target（新增 crop）
     → 重新 coverage
```

fast 模式默认不创建：

```text
propose_regions
roi_screen / roi_screen_batch
普通 hybrid_scan
feature_scan
needle_scan
```

## 3. 类别来源与分工

```text
Plan A → 药材种类
YOLO → 显微特征类别 + 框
GLM locate → 指定特征候选框
CNN stage2 → crop 的 14 类特征
GLM classify → stage2 低置信/other 的身份兜底
```

- YOLO 不输出药材结论。
- CNN 不生成框，不能替代 locate。
- GLM locate 不负责最终分类，必须由 stage2/GLM classify 复核。
- GLM classify 不重新定位；required crop 的 YOLO crop 复核只是辅助。

## 4. 前置条件

| 工具 | 前置 |
|---|---|
| `detect_fov_initial` | 原图已绑定 |
| `detect_region` | 合法 ROI 或 crop |
| `calibrate_fov` | 原图/标尺可用 |
| `propose_regions` | 原图/检测工件；非 fast |
| `roi_screen` | 区域提议完成；非 fast |
| `roi_screen_batch` | 多视野区域提议完成，且缺失 screen；非 fast |
| `needle_scan` | 原图已绑定；`needle_scan_enabled=true` |
| `feature_scan` | 原图已绑定；`feature_scan_enabled=true` 且 feature 合法 |
| `hybrid_scan` | 原图已绑定；`hybrid_scan_enabled=true`；A 候选提供 missing required feature；fast 中仅 fallback |
| `locate_feature` | screen top-k 或 fallback ROI |
| `classify_target` | 合法 crop；fast 中所有 YOLO/GLM crop 都可分类 |
| `image_exemplar_audit` | 合法 crop；示例库存在 |
| `segment_instance` | crop 身份满足、尺度可用 |
| `measure_instances` | 合格 mask、标定、用途资格 |

## 5. locate 质量约束

```text
locate_min_roi_side = 256
locate_min_box_side = 90
locate_expand = 1.5
```

- ROI 小于 256 时围绕中心扩展；
- tight box 小于 90 时扩展，保留 `source_tight_bbox`；
- 无目标必须返回 `{"objects":[]}`；
- 空结果不裁 crop；
- 同 ROI 的重复返回做 NMS；
- `det_score >= 0.8` 可走 `locate_override`；
- `blank + 低分` 不进入 segment；`blank + 高分` 保留后续；
- `low_detail` 只标记 review。

## 6. tile policy

```text
feature_scan_tile_policy = full
fast_fallback_max_locate_calls = 12
```

`full`：

```text
4 个 tile 全部并发
→ 任一 crop：合并继续
→ 全部空：立即返回空，不重试
```

`prescreen`：

```text
先扫纹理最强 pilot
→ pilot 空：停止该 feature
→ pilot 有 crop：继续剩余 tile
```

`fast_fallback_max_locate_calls` 限制一次 fallback 的总 locate 数。`3 feature + 12 cap` 时每 feature 最多 4 tile。

## 7. 当前未实现

- locate 全局批量并发。

这些未完成项不能写成已实现工具。

## 8. 旁路审计

`needle_audit` / `feature_audit` 在 workflow 结束后读取已有 crop、classification 和 mask：

```text
feature_audit/feature_audit.json
```

内容包括：

```text
candidate 的 audit_label / target_score / negative_margin
high_score_unclassified
mask 的 connected components / skeleton / merged
```

它不参与 `decide`，不阻断高分 mask/measure；失败只写 audit error。
