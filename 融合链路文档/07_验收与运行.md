## 4. fast 模式验收表

| 要核验的事实 | 工件 |
|---|---|
| 动作生命周期/等待时间 | `workflow/action_timeline.json` 的 offered/selected/started/ended |
| 输入哈希、N 张图、空缓存 | `input_proof.json`、`config.json`、`interface_status.json` |
| A 每图五折和每折 Top-K | `a_prediction.json` 的 `view_predictions[].fold_rankings` |
| fast 配置实际生效 | `config.json` 的 `fast_yolo_stage2` / `fast_fallback_max_features=2` / `fast_fallback_max_locate_calls=6` / `feature_scan_tile_policy` / `auto_measure_after_segment` / `suppress_repeated_measurement` / `supporting_probe_*` |
| YOLO 是否真的产出框 | `workflow/ops/*/boxes.json`、`workflow/ops/*/crop_context.json`、`yolo.log` |
| 自动标定失败是否只置空尺度 | `detect` operation 的 `boxes.json` 存在、`crops.json` 存在、`px_per_um` 可空 |
| CNN batch 是否先分类 | `workflow/ops/*/classification.json` 的 `confidence_source=cnn` |
| 是否错误地跑 propose/screen | `workflow/operations.json` 中 `propose_regions` / `roi_screen` 数量应为 0（fast 默认） |
| required fallback 是否受控 | `hybrid_scan` 数量、`features[]`、`max_locate_calls` |
| 4 tile 是否全并发 | `glm_*/scan/tile_*/stage.log`、`scan_result.json` 的 `count/stopped` |
| 全空是否立即结束 | `feature_scan` 返回空后是否仍重复同一 target |
| fallback 是否只补缺失 | `coverage` / `missing_required` 与 `hybrid_scan` feature 是否一致 |
| 身份门是否生效 | `identity_pending` → `classify_target` 顺序 |
| 分类标签 | `output.json.classifications`、classification.json |
| 暂定排序是否旁路 | `output.json.provisional` 的 `formal_score/formal_support_count` 与正式 verdict 一致 |
| required_states 是否进入 Agent | `agent_trace.json` context / `workflow.required_states` |
| 每图 classify 上限 | `config.json` 的 `fast_classify_max_per_view` 与 operations 计数 |
| mask/测量 | `workflow/ops/`、IGM、measurement |
| B 裁决与融合 | `fusion.json`、`agent_verdict.json` |
| 停止后研判 | `final_evidence.json`、`final_assessment.json`、`report.md` |

## 5. 结果解读

```text
图片数量已绑定
≠ 每张图都完成 detect/classify
≠ 每个 crop 都有身份
≠ 每个身份都产出 mask
≠ 每个 mask 都允许测量
```

必须区分：

- A 先验；
- YOLO 框；
- GLM locate 候选；
- CNN/GLM 身份；
- IGM mask 质量；
- 物理尺寸；
- 原规则结论；
- 文本倾向。

`fused_score` 是排序分，不是校准正确率；`review_required=true` 和 `insufficient_evidence` 必须保留。

## 6. 当前限制

- `classify_target` 保留单 crop 路径；`classify_crops_batch` 提供逐实例批量 CNN，二者共享缓存；低置信批量结果进入 pending_review，可继续单实例复核；YOLO batch/GPU 未实现；
- YOLO 仍逐图、默认 CPU；
- locate 未全局批量并发；
- fallback 4 tile 全空即弃，不能保证零漏检；
- 没有合格身份、mask 或标定时可能没有 μm。

## 7. 失败处理

- 输入校验失败：不创建 case；
- doctor 失败：写 `interface_status.json`，不启动 pipeline；
- `detect_fov_initial` 的 YOLO 成功但自动标定失败：保留框，`px_per_um=None`；
- 运行失败：在新 case 中保留错误和已产生工件；
- 不用旧 pending 续跑；重试创建新 case；
- 不覆盖历史 `case_9cc59640`。
