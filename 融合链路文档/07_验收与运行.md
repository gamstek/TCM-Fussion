# 07｜验收与运行

同步版本 v4.0｜2026-11-04。在项目根执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m TCM_Fusion.cli.main selftest
.\.venv\Scripts\python.exe -X utf8 -m TCM_Fusion.cli.main doctor --config TCM_Fusion/config/demo.json
.\.venv\Scripts\python.exe -X utf8 -m TCM_Fusion.cli.main agent-demo --transport mcp --top-k 3
```

`doctor` 是本地预检，`agent-demo` 使用替身响应。真实单图配置见[手册](../单图测试操作手册.md)，需要可用权重、运行环境和服务配置。每次新任务用原图及新缓存；人工标签只做事后评估。

| 要核验的事实 | 工件 |
|---|---|
| 五个模型各自输出及每折截断 | `a_prediction.json` 的 `fold_rankings` 和配置中的 K |
| 模型是否实际选了工具、为什么停 | `agent_trace.json` 的动作、反馈、拒绝、预算和停止原因 |
| 工具是否真产生框、mask、尺寸 | `workflow/ops/`、操作账本及版本化工件 |
| 是否确认药材 | `agent_verdict.json`、`fusion.json` |
| 反思是否生效 | 区分任务卡、显式加载的 `prompt_version` 与模拟 `reflection_version` |

默认每折 3 个。真实 CNN 冒烟中，`11.jpg` 从逐折榜单找回候选大青叶，`3_64a87d.jpg` 的龙胆仍未入榜。候选覆盖、定位 IoU、最终纠错、误改、复核、调用次数和耗时分别统计；冒烟无法估计总体收益。
