| 术语 | 当前含义 |
|---|---|
| A | 五个折模型各自推理，分别提供 Top-K。默认每折 3 个 |
| B | 检测、标定、分割、测量、视觉观察及原规则裁决 |
| C | LangGraph 编排与 MCP 工具调用 |
| 候选兴趣 | 逐折榜单映射、去重后供补查的药材集合；不裁剪 B 规则候选 |
| 任务内 Reflection | 从本次动作反馈生成一次结构化提示卡 |
| 离线 Reflection / LangMem | 由显式命令生成候选、开发集回放、验证与发布 |

原图 → A / B 工件 → Agent 查证 → 原规则 → 融合报告。逐折候选、可执行动作及最终裁决是三个独立概念。
