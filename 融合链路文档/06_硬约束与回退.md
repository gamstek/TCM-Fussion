# 06｜硬约束与回退

同步版本 v7.0｜2026-11-17。用于判断哪些结果可以采信、哪些只能保留为未知。

## 1. 输入硬约束

- manifest `views` 至少 1 项；
- 每项必须有 SHA256；
- 路径必须在 source-dir 内；
- 路径和内容不能重复；
- A 解释器必须显式提供；
- 新 case 必须空 A 缓存；
- 参考标签、人工框和参考结论不得进入规划配置。

违反输入约束时，不创建 case；已创建 case 的失败写 `interface_status.json`。

## 2. Fast 路径硬约束

```text
fast_yolo_stage2 = true
```

- YOLO 框全部保留，GLM 不覆盖 YOLO 同特征框；
- CNN batch 先分类；低置信/other 才回退 GLM；
- 标准路径不创建 `propose_regions` / `roi_screen` / 普通 `hybrid_scan`；前两者已移除；
- 只有 missing required feature 才创建一次 fallback；
- fallback 的 `max_locate_calls` 必须被遵守；
- `full` 4 tile 全空即弃，不重试；
- 不把 fallback 空结果当成“目标不存在”，只保留 unknown。

## 3. 身份与类别

- `identity_required` 的低分 locate crop 未分类时，必须先 classify 最高 `det_score` crop；
- classify 失败/不可判不会无限重试，但也不会自动升级为针晶；
- 任何 `identity_required` crop 未分类/未确认时不得绕过身份进入 segment/measure；
- `纤维`、`花粉粒`、`图像不可判` 都不是 `needle_crystal`；
- YOLO crop 复核未命中时，不允许把 YOLO 当作正向身份。

## 4. 框与质量约束

```text
locate_min_roi_side = 256
locate_min_box_side = 90
locate_expand = 1.5
```

- 观察 ROI 小于 256 时围绕中心扩展；
- tight box 小于 90 时围绕中心扩展，保留 `source_tight_bbox`；
- 不直接丢弃小目标；
- 无目标必须返回 `{"objects":[]}`；
- 空结果不裁 crop，不伪造 evidence；
- `blank/low_detail` 只保留分类/待核验，不进入诊断性 segment；
- 高分 `det_score` 只影响定位优先级，不绕过身份门；
- 同特征 GLM 与 YOLO IoU >= 0.5 时保留 YOLO。

## 5. 尺度、mask 与测量

- 物理尺寸必须来自可信 `px_per_um` 和合格 mask；
- `detect_fov_initial` 自动标定失败只置 `px_per_um=None`，不回滚 YOLO 框；
- 后续可显式 `calibrate_fov`；
- IGM `review` 不自动等于 `valid`；
- 不允许用高 `det_score` 把 review 改成 valid；
- 没有 mask、尺度或用途资格时保留未知，不退化为 0；
- 不能为了得到 μm 伪造 mask、尺度或身份。

## 6. 扫描并发边界

`feature_scan` 允许 tile 并发，但：

- 并发只发生在同一视野的独立 tile；
- 每个 tile 结果必须绑定自己的 image_id、feature_id 和 tile 坐标；
- 由 `WorkflowSession` 一次提交，避免并发写 `operations.json` 和证据版本；
- 任一 tile 失败必须可定位；
- 4 tile 全空按空结果处理，不重试，也不当成阴性。

`roi_screen_batch` 等旧批量筛选工具已随标准路径移除。

## 7. 旁路审计

`feature_audit`：

- 调查结束后读取当前有效证据版本，工件的 ID、依赖和摘要来自快照；
- 不参与 `decide`、不修改证据、不阻断高分 mask/measure；
- `high_score_unclassified` 和 `classification_unresolved` 都是诊断缺口，仍需核验；
- `merged` 表示 mask 可能含多根，不能直接当单根尺寸。

## 8. 预算与停止

```text
max_initializations = N + initialization_reserve
max_locate_attempts = max(4, per_view*N + reserve)
feature_scan_tile_policy = full
fast_fallback_max_locate_calls = 6
max_planning = 60
max_observations = 40
max_api_calls = 200
max_resource_units = 400
```

预算耗尽、硬截止、无合法动作或模型请求复核都进入收尾；停止不是阴性诊断。

## 9. 回退

| 情况 | 回退 |
|---|---|
| A 解析/折数/榜单非法 | 该次运行报错，不伪造候选 |
| YOLO 检测成功、自动标定失败 | 保留框，`px_per_um=None`，后续 calibrate |
| 服务失败/超时 | 保留 unknown，记录 error_code，不按缺失目标处理 |
| locate 返回空 | 记录空结果，不裁 crop，不伪造 evidence |
| fallback 4 tile 全空 | 该 feature 结束，不重试；required 仍缺失则 review |
| classify 不可判 | 记录 reject，不进入针晶测量 |
| 无合格 mask/尺度 | 无 μm，保留 review |
| 文本收尾失败 | 程序化 final_assessment |
| 批量子任务失败 | 定位到具体视野；不污染其他结果 |

## 10. 暂定排序边界

- `provisional_score` 只用于候选排序和 Agent 补查建议；
- `formal_score`、`support_count`、正式 evidence class 不受 0.5/0.25 影响；
- `VERIFIED_MATCH` 才可进入正式确认；
- `DETECTED_PENDING` / `PARTIAL_MATCH` 不把 required 标成满足；
- `CONFLICT` 不降成 0.25；
- 同一 crop 只取一个最佳 classification；同一判据只计一次；
- 0.8 只是暂定准入试验值，不是正确率保证；按来源/特征校准。

## 11. 当前未实现

- `classify_crops_batch` 已提供；YOLO batch/GPU 未实现；
- YOLO batch/GPU；
- locate 全局并发；
- 多图并行准备（detect/classify/scene）尚未实现。

这些是待实现能力，不是配置开关；文档不得声称已支持。
