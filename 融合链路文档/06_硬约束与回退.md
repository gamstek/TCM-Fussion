# 06｜硬约束与回退

同步版本 v4.0｜2026-11-04。用于判断哪些输出可以采信和何时回退。

| 条件 | 执行与回退 |
|---|---|
| 候选映射缺失或不一致 | 保留逐折原始标签与未映射记录；只能为可映射候选查询判据 |
| 存在性、分类或场景观察 | 受工具及特征等级约束；不能将模型回答转换为尺寸或最终药材结论 |
| 无可信尺度或 mask | 保留未知和质量诊断；不给物理尺寸采信 |
| 强制场景未完成、还有依赖待修复或证据仍需复核 | 运行时否决确认，可继续合法动作或申请复核 |
| 规划格式错误、超预算、服务失败 | 记录拒绝详情、预算与停止原因；有界重提。服务失败不能按缺失目标处理 |
| 重算、回放、模拟 | 版本化新工件，来源与身份校验；回放缺合法工件时保留未覆盖状态 |

A 的每折 Top-K 只提供补查方向，B 按完整允许候选评分。五折分数和规则分数分别报告。反思可改变查证策略，规则、原始工件及用途资格由受信程序维护。报告中的 `needs_review` 是状态，不自动派给审核员。
