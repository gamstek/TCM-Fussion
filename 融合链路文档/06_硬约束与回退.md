# 06｜硬约束与回退

同步版本 v5.0｜2026-11-08。用于判断哪些结果可以采信、哪些只能保留为未知。

## 1. 输入硬约束

- manifest `views` 至少 1 项；
- 每项必须有 SHA256；
- 路径必须在 source-dir 内；
- 路径和内容不能重复；
- A 解释器必须显式提供；
- 新 case 必须空 A 缓存；
- 参考标签、人工框和参考结论不得进入规划配置。

违反输入约束时，不创建 case；已创建 case 的失败写 `interface_status.json`。

## 2. 身份与类别

- `identity_required` 的低分 locate crop 未分类时，必须先 classify 最高 `det_score` crop；
- classify 失败/不可判不会无限重试，但也不会自动升级为针晶；
- `det_score >= 0.8` 可走 `locate_override`；低于 0.8 不得绕过身份；
- `纤维`、`花粉粒`、`图像不可判` 都不是 `needle_crystal`；
- YOLO crop 复核未命中时，不允许把 YOLO 当作正向身份。

## 3. 尺度、mask 与测量

- 物理尺寸必须来自可信 `px_per_um` 和合格 mask；
- IGM `review` 不自动等于 `valid`；
- `locate_override` 只提供诊断性 IGM/测量资格，不把 review 改成 valid；
- 没有 mask、尺度或用途资格时保留未知，不退化为 0；
- 不能为了得到 μm 伪造 mask、尺度或身份。

## 4. 批量 screen

`roi_screen_batch` 允许 worker 并发，但：

- 并发只发生在独立视野；
- 每个视野结果必须绑定自己的 image_id；
- 由 `WorkflowSession` 一次提交，避免并发写 `operations.json` 和证据版本；
- 任一子任务失败必须可定位到具体视野；
- 批量失败不能把全部视野当成阴性。

## 5. 预算与停止

```text
max_initializations = N + initialization_reserve
max_locate_attempts = max(4, per_view*N + reserve)
screen_concurrency = 3
max_parallel = 2  # 仅独立观察
max_planning = 32
max_observations = 10
max_api_calls = 60
max_resource_units = 220
```

预算耗尽、硬截止、无合法动作或模型请求复核都进入收尾；停止不是阴性诊断。

## 6. 回退

| 情况 | 回退 |
|---|---|
| A 解析/折数/榜单非法 | 该次运行报错，不伪造候选 |
| 服务失败/超时 | 保留 unknown，记录 error_code，不按缺失目标处理 |
| classify 不可判 | 记录 reject，不进入针晶测量 |
| 无合格 mask/尺度 | 无 μm，保留 review |
| 文本收尾失败 | 程序化 final_assessment |
| 批量子任务失败 | 定位到具体视野；是否回退单视野由后续合法动作决定，不污染其他结果 |

## 7. 当前未实现

- `classify_batch`；
- YOLO batch/GPU；
- locate 批量并发。

这些是待实现能力，不是配置开关；文档不得声称已支持。
