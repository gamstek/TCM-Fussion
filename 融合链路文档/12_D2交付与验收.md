# D2｜区分问题、证据资格与实例关联歧义

版本 v1.0｜2026-11-17｜对应 [10 实施方案](10_ReAct主导的证据优化与语义DAG实施部署方案.md) §九 D2。D1 的历史交付见 [11](11_D1交付与验收.md)。

## 1. 目的与边界

让 Agent 在下一轮就看到“哪些问题可共享、哪些证据只能作线索、哪些目标可能重复、哪些差异当前知识库无法回答”。ReAct 仍逐轮选择调查目标、工具和停止；保留自动 required 分割/测量，没有引入 DAG、独立审查模型或多 Agent。

物理观察与候选解释分开：同一视野上的通用纤维存在性可以只问一次，但各候选的壁厚、排列和尺寸要求仍须分别解释。通用阳性不等于全部 required 已满足。

## 2. 实现与真实接口

## 3. 数据与控制流

```text
原图/现有工件 + 当前观察 + 原规则检查
→ 资格投影 / 区分问题 / 关联歧义
→ ReAct 读取有界摘要
  ├─ 需要细节 → 可选择分页只读工具 → 再规划
  ├─ 需要观察 → 在合法动作中选通用存在性或其他既有工具
  └─ 证据不足/任务结束 → 原规则裁决 + 共用引用校验
```

默认摘要每类最多 8 项；资格列表每个字段最多 3 条引用或缺口；问题的消费者摘要最多 8 个。完整五折候选并集仍保留，`total/omitted/detail_access` 明示省略，不能据此排除未展示候选。细节读取依然消耗一次动作，若需模型规划也照常消耗规划预算；“只读无视觉请求”不等于整步零成本。

`adaptive_v2` 的通用形态提示来自现有 taxonomy。实际的专门形态问题、量纲或视野不同，不共享查询键。候选名不进入通用视觉问题；required/supporting 是消费者角色，不是不同原图观察。

## 4. 资格与失败处理

- 原先验、假设、分类工件存在及失败操作不能单独作药材支持。A 仍完整保留为先验和独立输出，不因取消其正式证据资格而删除 A 结果。
- 未标定的尺寸、没有满足定量条件的 `NO_REF`、不允许的 QA 量纲，在循环内标为缺口或不合格量纲；合法存在性仍可继续使用。`OUT_OF_RANGE` 是可用量纲上的不匹配，不等于测量本身无效。
- 观察失败/低置信是 unknown；有效未见只描述检查过的视野，不排除整个样品。局部反证也不意味着候选被删除。
- 事实 ID 绑定相关工件、观察和评估版本。无关提交不重新编号；相关评估改变后，旧引用不能被当作新版本引用。
- 高重叠/包含只产生关联候选，不自动合并，不授予身份或尺寸资格。D1 精确坐标索引保留；新输入与旧输入的失败尝试区分。新 crop 有实际输入变化时，不再仅凭旧高 IoU 失败记录阻断调查。
- `kb_indistinguishable` 仅描述 KB 已声明的组内成员边界；`kb_incomplete`、`budget_blocked`、`missing_prerequisite` 分开报告，不制造药材组或自动扫描计划。Agent 仍可调查其他合法问题或转复核。
