# 03｜接口契约

同步版本 v6.0｜2026-11-10。用于连接真实 A、多图接口、规划器与 MCP。

## 1. 多图接口

```text
run_multi_view(source_dir, *, output_root=None, manifest=None,
               config_template=None, a_python=None, dry_run=False,
               case_name=None)
```

输入 manifest：

```json
{
  "views": [
    {"view": "a.jpg", "sha256": "<sha256>"},
    {"path": "sub/b.jpg", "sha256": "<sha256>"}
  ]
}
```

约束：

- `views` 至少 1 项；
- 路径在 source-dir 内；
- 路径、内容唯一；
- SHA256 必须匹配；
- 参考标签不写入配置。

输出：

```text
dry_run=true  → 准备 case 目录
dry_run=false → runs/<run_id>
```

`case_name` 只影响目录名；`sample_id` 另做 ASCII 清洗。`case_name` 不能为空，不能包含 `<>:"/\|?*` 或控制字符，不能是 `.`/`..`、Windows 保留名（`CON`、`PRN`、`AUX`、`NUL`、`COM1-9`、`LPT1-9`），不能以空格或点结尾，且不超过 100 字符；违规统一返回 `MULTI_VIEW_NAME`。

## 2. 配置契约

```text
config/multi_view.json
```

当前关键字段：

```text
agent.mode=active
agent.planner=llm
agent.transport=mcp
agent.workflow.execution=active
agent.workflow.agent_policy=adaptive_v2
agent.workflow.detector=yolo
a.mode=cli
b.mode=run
allow_recorded=false
```

### Fast 路径字段

```json
{
  "fast_yolo_stage2": true,
  "fast_fallback_max_features": 3,
  "fast_fallback_max_locate_calls": 12,
  "feature_scan_tile_policy": "full",
  "feature_scan_max_tiles": 4,
  "feature_scan_concurrency": 4
}
```

含义：

```text
fast_yolo_stage2
  YOLO 先检，CNN batch 分类所有 YOLO crop；
  不默认创建 propose/screen/hybrid。

fast_fallback_max_features
  样本的整组视野仍缺 required feature 时，每次最多补几个 feature。

fast_fallback_max_locate_calls
  一次 fallback hybrid 的总 locate 上限。

feature_scan_tile_policy
  full：4 tile 全并发，全空即弃；
  prescreen：先 pilot，空即停。
```

### Locate / quality 字段

```text
screen_max_rois = 4          # screen 输出 ROI 上限，不减少输入 192 区域
locate_expand = 1.5
locate_min_box_side = 90     # tight box 最小边
locate_min_roi_side = 256    # GLM 观察 ROI 最小边
glm_locate_threshold = 0.8   # 高分绕过质量门
box_quality_enabled = true
box_quality_retry = true
```

### Stage2 字段

```text
cnn_weights / cnn_meta
cnn_threshold = 0.75
cnn_entropy_threshold = 0.8
cnn_batch_size = 16
cnn_other_fallback = true
```

### Hybrid / coverage 字段

```text
hybrid_scan_enabled = true
hybrid_scan_max_features = 2
agent_driven_coverage = true
screen_top_k = 2
screen_concurrency = 3
```

`hybrid_scan` 在 fast 模式下只作为 missing required feature 的 fallback；普通视野不创建。

## 3. A 契约

```text
predict_a / a_prediction.json
```

每图五折：

```text
view_predictions[].fold_rankings
```

每折包含：

```text
rank / label / probability
```

Agent 默认每折 Top-3。折数不一致、榜单非法或缺少逐折数据时拒绝该 A 结果。

## 4. B 工具契约

单图/ROI/crop 目标：

```text
detect_fov_initial(image_id)
propose_regions(image_id)         # 非 fast 可选
roi_screen(image_id)              # 非 fast 可选
roi_screen_batch(screen:batch)    # 非 fast 可选
locate_feature(locate:roi:...)
classify_target(crop:...)
segment_instance(crop:...)
measure_instances(seg:...)
```

fast fallback：

```text
hybrid_scan:<image>
features[]: missing required feature
max_locate_calls: 12
```

`feature_scan`：

```text
feature_scan:<image>:<feature_id>
max_tiles: 每个 feature 的 tile 上限
```

`locate_feature` 参数：

```text
roi / feature_id / locate_expand / locate_min_box_side / locate_min_roi_side
```

## 5. 动作与证据

规划器只能选当轮合法 `action_id`。运行时校验：

- 工具是否启用；
- 目标/参数是否匹配；
- 前置工件；
- 身份/标定/质量；
- 证据版本；
- 网络、观察、重算、资源预算。

`identity_pending` 是动作门：

```text
未分类 identity crop
→ 只允许 classify 最高分 crop
→ 清除 stop 建议
```

高分 `locate_override` 例外。

## 6. scale 契约

```text
crop.px_per_um 可为空
```

- `detect_fov_initial` 自动标定失败时保留 YOLO 框，`px_per_um=None`；
- 后续 `calibrate_fov` 可补；
- 没有可信 `px_per_um` 时不得输出 μm；
- 不能因为自动标定失败丢弃检测框或伪造尺度。
