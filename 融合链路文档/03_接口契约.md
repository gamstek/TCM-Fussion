# 03｜接口契约

同步版本 v4.0｜2026-11-04。用于连接真实 A、规划器与 MCP。

| 接口 | 现役契约 |
|---|---|
| `predict_a(config, cache_dir)` | 真实 CLI 模式返回 `ranking`、`folds`、`fold_rankings`。每折榜单按名次排列，每条含 `rank/label/probability` |
| `candidates(a, kb, aliases=None, config=None)` | 逐折返回 `source=fold_top_k`、`ids`、`fold_top_k`、`unmapped`、`candidate_incomplete`。每条候选保留原始分数及映射 ID |
| `EvidenceRuntime.summary(state)` | 提供规则摘要、观察、卡片、候选兴趣及判据差异。MCP 从同一 A 工件构造运行时 |
| `run_pipeline(config, *, base=None)` | 写任务、路由、观察轨迹、裁决与融合报告 |
| 规划器 | 在线按当轮短编号 `action_id` 选择，运行时映射回注册动作。覆盖停止建议时填 `override_reason` |

`agent.candidate_policy.top_k` 合法值为 1～68。显式配置优先，其次继承 `routing.top_k`，无配置时真实逐折路径默认 3。逐折路径不按累计概率截断；`cumulative_mass` 只参与缺逐折榜单的历史兼容路径。

真实 A 缺逐折数据、折数不一致或榜单非法时，适配器报错。动作不可用时写匹配类型和剩余预算，服务超时或失败保持未知。CNN 折内分数未经校准。详见[候选策略源码](../lib/candidate_policy.py)和[动作校验源码](../lib/react_graph.py)。
