# differential_presence · 核验特征存在性

核验某项显微特征在指定视野是否可见。多个候选可以引用同一次观察。

## 适用条件

候选比较仍有缺口，且当轮菜单提供 `presence_check` 时使用。运行时可为知识库中 P1 或 C 层级的必需项（required）和辅助项（supporting）提供该动作。纯辅助探查受专门额度约束。如果同一观察也服务活动候选的必需项，这次调用计入常规资源预算，保留专门的辅助探查额度。

## 行动选择

- 选择本轮绑定好的 `image_id`、`feature_id` 和 `morph_hint`。视觉请求使用该特征的通用形态描述。候选名、预期药材和各自的参考范围留待解释时使用。
- 同视野、同特征、同问题可以共用回执。若候选实际区别在宽度或特定形态，先判断该观察能推进哪一步。已有合格观察时可直接核对判据，缺尺寸时可选择实例测量。
- 从当轮菜单按顺序选择各自值得调查的原图问题，数量以 `execution_options.max_questions` 为准。多批观察每批最多并发两项，各问题分别计费。若后项取决于前项反馈，先选前项；有新线索或调查方向变化时重新规划。

## 结果与边界

| 经运行时核验的回执 | 可以怎样解释 |
| --- | --- |
| `present=true`，`conf` 在 0.5～1 之间 | 为这个视野和特征增加未标定的定性支持。各候选的形态与量纲要求仍分别核验。 |
| `present=false`，`conf` 在 0.5～1 之间 | 保留本视野有效未见。若当前只有部分视野有效未见、其余未查，且没有其他合格支持或反证，候选账本记 `local_absent_partial`。即使全部输入视野都未见，也不能据此排除整份样品。 |
| 低置信、调用失败或无有效回执 | 保留 `unknown`。已消耗的额度和失败记录仍可追查。 |

回执可附以实际发送图像像素为基准的定位框。运行时负责坐标映射和来源校验。无框阳性仍按定性规则解释。有框时，影子裁图供目检和后续定位参考。它没有正式实例身份或测量资格。需要量化时，从当前合法的定位、分类和测量入口取得正式工件。

## 示例

两个候选都关心分泌组织，其中一个还对宽度有要求。一次“本视野可见分泌组织”的合格观察可以由两者共享。宽度判据继续保留待核验状态，等到取得同一实例的合格测量再判断。
