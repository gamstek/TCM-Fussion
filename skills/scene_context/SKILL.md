# scene_context

触发：当前有效卡池检出结晶，或运行时要求完成强制场景检查。

逐个注册视野检查；`adaptive_v2` 可在合法动作中安排时机，但强制场景未完成时运行时否决确认。

工具：`scene_check(image_id)`。只答画面细胞结构、结晶位置、排列与丰度；不得收到 A 标签、候选药材名或参考真值。

验证：复用原 VLMClient 场景提示与细胞壁守卫；失败、缺视野或预算不足必须转复核，不伪装完成。

产物：有图像哈希与 action_id 引用的观察，经原 `merge_vlm_scene` 和 `decide` 重评分；不计入 D8 特征数。场景描述不是目标身份，也不能直接补写针晶判据。
