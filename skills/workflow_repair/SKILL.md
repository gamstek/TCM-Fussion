# 工作流修复

先查询原图、crop、mask、尺度和失败状态。优先修复阻塞依赖，再做鉴别观察；只选当前合法目标。检测归检测侧，尺寸只来自真实mask和可信标定。无尺度时不采信尺寸，仍可选择不依赖尺度的合法工具；预算耗尽按当前状态收尾；不把A猜测或人工真值送入视觉提示。

adaptive_v1 / adaptive_v2 下逐工具检查前置条件：缺测量不阻止独立合法P1/C核验；需要尺寸的判据仍等待可信测量。明确本轮问题、预期解决项和停止条件。若启用并发，只并发独立观察与物理阶段，不并发同目标的分割与测量。服务失败不靠换ROI重试。

purpose_v1用read_quality区分完整性、诊断、用途资格。中心点未命中不是自动判错；身份未知、触边、极性及粘连疑点不能忽略。review mask不自动提供阳性存在性或尺寸，资格由程序生成。反思仅调整动作策略，不改工件、尺度、判据、权限或资格。

启用定向补救时，依据实际证据缺口决定是否提议区域。区域线索是纹理评分，不能当作特征存在证据。对所选区域可用局部 YOLO 或 GLM 定向定位，也可以换视野、改查其他合法证据或停止。优先检查能影响裁决的缺口。GLM 提出的框必须经过单独身份核验，才允许分割。GLM 定位无结果表示未知。
