# ADR-001 · 裁决层演进：证据数量门槛（已采纳）与 LLM/学习式裁决（评估后暂缓）

- 日期：2026-09-15
- 状态：**部分已采纳**——D8 证据数量门槛已实现；**方案 D（LLM 有界仲裁者）已落地影子最小实现**（`scripts/adjudicator.py`，仅建议不改 verdict，`--shadow-adjudicat` 显式开关）；LLM 全量接管与学习式打分**仍挂起待真实数据**
- 关联：设计方案 §5.4（裁决带/升级路径）、§11 Q2（验收线）；README 决策表 D8
- 落码：`scripts/rule_engine.py`（`MIN_SUPPORT_FEATURES` + decide() 门槛）、`scripts/report.py`（`support_feature_count` 透传）、`tests/test_rule_engine.py`（用例 3/4/5 改判 + 8/9 新增，共 26 项断言，现 57 项）

## 1. 背景与诱因

现行裁决是确定性符号评分：`C(h) = min(1, max(0,S_required)/Σ_required w)`，带阈值
confirmed(≥0.75, margin≥0.10) / probable(≥0.50) / group_level / insufficient_evidence。
（初稿此处另含"排他一票否决"，该层已于 2026-09-22 整体拆除，见 §3.3。）

真实数据暴露了它的病理：**单样本 20250378（仅 1 实例簇晶，feret_max=79.75μm）判出
`probable·虎杖 0.57`**，而辣蓼 0.26、大黄 0.17、G1 0.17 紧随其后。问题不在虎杖"错了"，
而在**一类常见特征根本不足以支撑任何倾向级结论**：

1. 权重（w=1.0/0.5/0.3）、五态 q 值全部手调，无数据校准；Σw 归一化还会让"判据多"的药
   被稀释（大黄 0.57/3.3=0.17），产生反直觉排名；
2. 线性加权和表达不了判据间的合取/否定逻辑；
3. "证据缺失"被隐式当成"证据不支持"，稀疏输入下置信度失控。

由此引出方案复审：是否改用 **LLM+skill 文档 / RAG / 其他知识存取方案** 做裁决？

## 2. 备选方案评估

| 方案 | 定位 | 评估结论 |
|---|---|---|
| A. 维持符号引擎现状 | — | 拒绝：单特征假阳性已被实证（§1）。 |
| **B. D8 证据数量门槛**（本 ADR 采纳） | 纯符号小补丁 | **采纳**：直击病灶（"1 类特征 → probable"），不改评分、只改带判定；可测、可解释、零依赖。 |
| C. LLM 整本《修正版》文档判药（skill/RAG） | 替换裁决者 | 暂缓：①量化区间比较跨 6 候选×多量纲，LLM 算术不可靠；②长文档检索易漏判据（lost-in-the-middle）；③**预训练先验混有药典类文本，不可枚举、不可版本化，破坏知识源封闭性**（另一种泄漏）；④端到端黑盒，错误无法归因到判据。 |
| **D. LLM 有界裁决者（bounded adjudicator）** | 增强 top-k 仲裁 | **已落地影子最小实现**：引擎出 top-k+评分分解 → `adjudicator.py` 在"带内模糊"案例（top1/top2 分差<0.10 且 verdict∈probable/insufficient）调用 LLM 产出倾向建议，程序端校验判据引用一致性、**不改 verdict**；CLI 需显式 `--shadow-adjudicat` 才启用。全量接管仍挂起，待真实批次在影子模式实测占优后按 §5 启用。 |
| E. Prolog/Datalog 逻辑规则 | 更聪明的符号 | 暂缓：85 味×四元组规模下收益不抵运维成本；若未来判据合取逻辑增多再议。 |
| F. 学习式打分（贝叶斯/GBDT 校准 w、q） | 替换评分核 | **这是权重手调问题的根治方向**，但依赖真实标注测量数据（正是检测/分割管线在产的）。结论：**治这个病的是数据，不是 LLM**。 |

关键论证：判药是两个子问题的复合——(a) 检索与约束过滤（"哪些药要求 20–160μm 簇晶且带网纹导管"）
是数据库查询，符号倒排索引又快又全可审计，embedding-RAG 与 LLM 在此都是更贵的错误工具
（KB 主键本就是精确 feature_id）；(b) top-k 内不完全证据下的仲裁才是 LLM 可能的增量所在。
现行设计把 VLM 限定为"只补事实、不裁决"（协作约定 3），与 (a)/(b) 切分一致。

## 3. 采纳的决定（D8）

1. 常量 `MIN_SUPPORT_FEATURES = 2`；**独立证据特征**＝该候选 `checks` 中
   present、状态非 OUT_OF_RANGE/NOT_DETECTED、`score_contribution > 0` 的**不同 feature_id**
   （同特征多量纲只计 1 类——射干针晶"长+宽"是两条判据、一类证据）。
2. 门槛作用于全部阳性和解：**confirmed / probable / group_level 一视同仁**（组级也不豁免：
   单特征同样分不出组）。不满足 → `verdict=insufficient_evidence`，`conclusion=None`，
   原 top1 插到 `alternatives` 首位（信息不丢），`needs_review=True`，notes 记录降级原因。
3. ~~**排他升级路径（suspect/suspect_adulterated）豁免 D8 门槛**~~ —— **【2026-09-22 废止】**
   该条已随排他（一票否决）层整体拆除而失效：库内两条否决规则（EX-DH-1 石细胞、EX-DH-2 簇晶
   <45μm）的唯一出处是一份**示例文档**（《一中药显微鉴别标准示例大黄粉末显微特征.docx》），
   非药典依据；用与多味药材共有的特征去否决真品，误杀风险大于收益。`suspect`/
   `suspect_adulterated` 两带、`exclusions`/`scope`/`suspect_subject` 字段与升级前件一并删除，
   D8 门槛对全部阳性和解一视同仁、无豁免路径。
   > 演进留痕：2026-09-21 曾把该豁免收紧为"被否决候选须本来就是最佳解释 + scope=sample"，
   > 用以修白芍样本被误升 `suspect(大黄)`；2026-09-22 判定**收紧不足以治本**（规则本身无据），
   > 故整层拆除。若将来获得药典依据的伪品区分判据，须作为新 ADR 重新论证是否恢复否决层。
4. `support_feature_count` 写入 decide() 输出与 `verdict.json`（schema 增量字段，
   `agent-judgement/v1` 向后兼容）。
5. 与 VLM 环的协同是设计的一部分：`insufficient_evidence` 恰在 `augment_and_rescore()`
   的介入时机内（agent_loop.py L114）——被 D8 拦下的样本若 VLM 补到第 2 类判据证据，
   重评分后可自然回到 probable。**门槛不降低召回，只拒绝"无佐证的独证"。**

- 端到端：20250378 判药 `probable·虎杖 0.57` → `insufficient_evidence`
  （`reports/single_20250378/`，旧产物备份 `*_preD8.*`）。
- demo 批（55 伪实例单簇晶样本）：`probable·白芍 0.50` → `insufficient_evidence`；
  eval 混淆对「大黄→白芍」→「大黄→(弃权)」，弃权率相应上升（`reports/eval_summary_D8.json`，
  对照 `eval_summary_preD8.json`）。
- 已知代价（接受）：真实批数据到位后**弃权率会显著高于 D8 前**——尤其显微特征天然稀疏的
  药材（矿物类、单特征定义药）。若实测弃权率过高，回退旋钮是把门槛改为"特征数或贡献权重
  和"的复合条件，或按通道分级（P0 独证可 probable，P1/C 独证不行）——改前必须重跑单测+demo
  回归并在本 ADR 追记。

## 5. 复审触发条件（何时重新评估 C/D/F）

1. 真实分割 mask + 多特征测量批数据 ≥ 可评测规模（几百样本）→ 三方 A/B：
   符号+D8 vs 学习式打分(F) vs LLM 有界裁决(D)，按 top1/弃权率/归因能力定夺；
2. 药典判据出现大量**组合逻辑**需求（现单条判据的量化区间 + 五态表达不了的，如"某特征必须
   与另一特征共现/互斥"）→ 重启 E；
3. VLM 证据质量经盲测确认可靠（Q6 预算批准）→ 优先落 D 的影子模式而非全量替换；
4. 任何 Q1–Q6 用户决议落地（设计方案 §11）→ 同步修订本 ADR。

## 6. 决策纪律声明

当前评测集是 n=1 的伪标签数据，"换任何裁决器更好"均无证据支撑。本 ADR 只做了**不依赖
数据规模即成立**的修正（独证不配倾向结论），把需要数据说话的分歧（权重校准、LLM 仲裁
增益）显式挂起——**让证据决定架构，而不是品味**。

## 7. 后续演进：候选级"宽区间主导"置信度 cap（2026-09-16）

- **诱因**：差分测试暴露马齿苋假阳性——`cluster_crystal 7~108` 区间极宽且该候选判据少
  （s_max 小），归一化后把"簇晶+淀粉"样本武断判为 `confirmed 0.80`，压过大黄(0.61)/虎杖(0.60)。
- **决策（规则引擎评分层，不改 D8/裁决带）**：新增候选级 cap——若某候选 `score` 由单一判据
  贡献占比 ≥ `DOM_SHARE_THRESHOLD`(0.55) 且该判据量化跨度 ≥ `WIDE_SPAN_THRESHOLD`(60μm)
  主导，则其 `confidence` 上限 `DOM_MAX_FACTOR`(0.60)，避免宽区间独证武断到 confirmed 带。
- **机理**：只惩罚"宽区间 + 判据稀缺"的投机候选；多判据真药（如大黄 cluster+vessel+starch
  三判据贡献分散）贡献占比不达标，不触发 → 正品不受损。
- **失败回退**：实测曾试"区间专属度乘性抑制"（跨度×覆盖候选数），因本征副作用被回退——
  它把大黄这类宽区间正品也压到相似档位、并暴露 G1（无 quant 判据 span 豁免）钻空、且马齿苋
  靠无量化淀粉 + 小分母仍占优，无法在不伤大黄的前提下压制马齿苋。cap 方案择其针对性强处落地。
- **实证**：样本 A"大簇晶+淀粉"马齿苋 0.80→0.60，大黄反超为 top(probable)；大黄正例(3 类证据)
  保持 confirmed。已知权衡：单判据宽区间候选（如虎杖仅 cluster）同样被 cap 至 0.60，预测更保守
  （倾向 insufficient/probable 而非虚高 confirmed）；如需放大可调 `DOM_MAX_FACTOR`/`DOM_SHARE_THRESHOLD`。
- **测试重构（数据驱动）**：用例数据从 .py 内联抽离为 `tests/cases/rule_engine.json`、
  `tests/cases/adjudicator.json`，runner 读取文件按 `kind` 断言语义执行。回归基线：
  **规则引擎 57 项、仲裁器 21 项全部通过**；新增混淆用例 ×1 锁定"不再武断 confirmed"。

## 8. 后续演进：D8b 单类证据条件放行（2026-09-22）

- **诱因**：`85味中药显微特征_修正版.md` ↔ `herb_criteria.json` 全量对账暴露——**59/85 味药典只给
  1 个显微判据**（非组 47 味：红花、板蓝根、虎杖、荜茇、麻黄、桂枝…），在 D8=2 下这批药**永远**
  只能输出 `insufficient_evidence`，与文档/判据库事实不符。本 ADR §4 已把"弃权率偏高"列为已知代价，
  但当时的处置是"回退旋钮待实测弃权率再定"；现在取到了第一个真实反例：
  **白芍样本（簇晶 16.1~23.2μm ∈ 药典 11~35，conf 1.00）仍被弃权**。
- **决策（裁决层，规则引擎）**：D8 门槛由"必须 ≥2 类"改为
  **「≥2 类 或（唯一证据类 且 `decisive` 且 conf ≥ `BAND_CONFIRMED`=0.75）」**。
  两道前提缺一不可：① `decisive`＝该类证据已把 top1 与并列者区分开（置信度分差 ≥δ=0.10，
  或独立证据类数不同）；② 达到 confirmed 置信带。放行的样本仍 `needs_review=True`（证据类数单薄）。
- **为什么不是"直接把门槛降到 1"**：实测门槛降到 1 后**白芍→confirmed（想要）**，但同时
  **虎杖样本→probable·大黄**（大黄/虎杖 conf 均 0.60、margin 0.00）——正是 D8 当初要拦的假阳性。
  加"decisive"前提后两者分开：白芍 margin 0.40 → 放行；虎杖 margin 0.00 → 继续拦。
- **边界（回归锁定）**：单类且 margin=0 的"方晶 G3/猪苓"、"极多簇晶 大黄/虎杖/马齿苋"、
  "针晶宽范 半夏/射干"、"未标定 UNCAL" 全部继续 `insufficient_evidence`；
  宽区间判据被 §7 的 DOM cap 压到 ≤0.60，天然满足不了 ②。
- **与 §4 旋钮的关系**：这等于选中了 §4 备选里的"复合条件"方案，但只选了"证据强度"一维，
  **未**按通道分级（P0 独证可 probable、P1/C 独证不行）——后者仍挂起。
  无量化 `required` 判据的品种（`NO_REF=0.6`）天然到不了 0.75，故本次放行只对**有量化的单判据品种**生效；
  纯定性药材（荜茇/槟榔/麻黄/连翘等 20 味）维持弃权（2026-09-22 用户决议：维持 `NO_REF=0.6`）。
- **测试**：规则引擎 42 → **44 项**（现 57 项）——"小簇晶单特征 → D8 拦截"改判为"D8b 条件放行 → confirmed·白芍
  且强制复核"，并断言放行前提 conf ≥0.75；仲裁器 21 项不变，全 PASS。
- **已知代价**：单类证据放行会把"该药恰有该特征"的风险从"弃权"变成"结论+复核"，
  靠 `needs_review` 与报告声明承接；若实测误判集中在单类放行样本，回退旋钮是把 ② 从
  `BAND_CONFIRMED` 提到更高（如 0.85），或要求该类证据为 P0 tier 且区间跨度为窄区间。
