# 为什么射干 0.4、G2 0.4、知母 0.4 并列？

样本：`needle_5view_zhiMu_9e4ef1ca`，view_01（`10.jpg`）只测到 1 个针晶实例：

- `feret_max = 80.636 μm`，`n_instances = 1`
- 掩码 `area_px=264202`、`aspect_ratio=2.36`、`solidity=0.862`、`convexity=0.428`
- 结论：**不是数值算错，而是当前证据只够“并列候选”，不够“确认”。**

## 1. 0.4 是怎么算出来的

规则引擎的置信度公式：

```text
score      = Σ w(tier) × q(state) × morph × m(abundance) × rel
confidence = score_required / Σ w_required
```

对射干、G2（半夏/法半夏/姜半夏组）、知母，`needle_crystal` 都是 **P0 required**，因此：

| 因子 | 值 | 说明 |
|---|---:|---|
| `w(tier)` | 1.0 | P0 通道权重 |
| `q(state)` | 1.0 | 80.636 μm 落在各自区间，`IN_RANGE` |
| `morph` | **0.4** | 掩码 `aspect_ratio=2.36 < 2.5`，针晶形态软核验给 0.4 |
| `m(abundance)` | 1.0 | 未声明丰度 |
| `rel` | 1.0 | 测量可信度 |
| **score** | **0.4** | 1.0 × 1.0 × 0.4 × 1.0 × 1.0 |
| `score_max` | 1.0 | 只有这一个 required |
| **confidence** | **0.4** | 0.4 / 1.0 |

三者的判据区间都覆盖 80.636 μm：

| 候选 | 判据 | 区间（μm） | 80.636 的结果 |
|---|---|---|---:|
| 射干 | `needle_crystal` required | 49–240（extreme 315） | IN_RANGE |
| G2（半夏/法半夏/姜半夏） | `needle_crystal` required | 20–144 | IN_RANGE |
| 知母 | `needle_crystal` required | 26–110 | IN_RANGE |

所以三个候选的 required 因子完全相同，`score`、`score_max`、`confidence` 都相同，排序自然并列。

## 2. 为什么 `morph` 只有 0.4

`Agent判药/scripts/rule_engine.py` 的 `morphology_plausibility("needle_crystal", card)`：

```python
a = s.get("aspect_ratio", 0)
return 1.0 if a >= 4 else (0.7 if a >= 2.5 else 0.4)
```

本次掩码是**一整束针晶的连通域**，不是单根针晶：`aspect_ratio=2.36`，因此 `morph=0.4`。
如果分割能把针晶束拆成单根（aspect ratio ≥ 4），`morph` 可到 1.0，`score` 会到 1.0；但**这仍然不够**，原因见下一节。

## 3. 为什么“理论上应该能确认”不成立

### 3.1 裁决带有硬门槛

- `BAND_PROBABLE = 0.50`，`BAND_CONFIRMED = 0.75`；0.4 连 probable 都不到。
- D8 要求 **≥2 类独立证据特征**；本样本 `support_count=1`（只有 `needle_crystal`）。
- D8b 允许“药典只有一个判据”的品种在 1 类证据时放行，但前提是：
  - 置信度达到 **confirmed 带（≥0.75）**；
  - 且该证据已把 top1 与并列者**区分开（decisive）**。
  本样本两条都不满足：0.4 < 0.75，且射干/G2/知母完全并列。

### 3.2 即使 `morph=1.0`，三者仍会并列

射干和知母都**只有** `needle_crystal` 一个 required 判据；G2 的 required 也只有针晶。若 `morph=1.0`，三者都是 `confidence=1.0`，仍然并列，D8b 的“decisive”仍不成立。要确认知母，必须引入**额外的区分证据**：

1. **语义形态核验**：射干的判据是“柱晶/棱柱形”，知母是“针晶成束或散在”。本管线有 `classify_target`，可对针晶 crop 做“针晶 vs 柱晶”的类别复核；本次 Agent 没有调用它。
2. **第二类独立证据**：G2 有淀粉粒/导管 supporting 判据，本次未测；测了可改变 `support_count`/D8，但也可能支持 G2 而非知母。
3. **更细的掩码**：把针晶束拆成单根，`aspect_ratio` 上去，`morph` 才有区分力；但单靠几何仍不能区分“针晶”与“细柱晶”。
4. **多视野 A 先验**：A 五折 25/25 为知母，但当前融合层没有把多视野 A 汇总成单一标签，无法用于并列排序；即使汇总，也只能作先验，不能单独当确认证据。

## 4. Agent 当时做了什么、为什么没解决

- 规划 17 次、GLM 观察 10 次；观察预算耗尽。
- 主要观察：fiber、crystal_fiber、scene_check、sand_crystal 等；这些用于排除黄芪/甘草/苦参/秦皮等候选。
- 它在第 26 步明确写道：“针晶支持知母、射干、G2 等候选但存在歧义”，随后选择 `propose_regions` 想扩大针晶样本量；`locate_feature` 也执行了，但没有产生第二个可测量针晶。
- **没有对针晶 crop 调用 `classify_target`**，因此没有产生“针晶 vs 柱晶”的语义证据。
- 强制 `scene_check` 和多次存在性核验占用了观察预算，最后 `observation=0`，只能转复核。

## 5. 结论与改进建议

- **0.4 不是 bug**：它是“一个 P0 判据、morph=0.4、只有 1 类证据、三个候选区间重叠”下的正确“证据不足”。
- 真正缺的是**区分证据**，不是再算一遍分数。
- 建议按优先级：
  1. 当同一测量对 ≥2 个候选都 `IN_RANGE` 时，强制先做一次 `classify_target`（针晶/柱晶/纤维）或语义形态核验，再决定是否继续 absence check。
  2. 对只有一个 required 判据的品种，允许“A 多视野一致 + 1 个 P0 测量 + 语义形态”作为 D8b 的候选路径，但仍保留人工复核标记；不要直接把 A 当结论。
  3. 分割侧把针晶束拆成单根，或至少输出 `n_needles`；单根 `aspect_ratio` 才能让 `morph` 有意义。
  4. 修多视野 A 的样品级聚合，让 `fuse` 能拿到“知母 25/25”作为并列排序先验。
  5. 预算策略：先做“能区分候选”的动作（classify/第二特征），再做“排除其他候选”的 absence check；本次顺序反了。
