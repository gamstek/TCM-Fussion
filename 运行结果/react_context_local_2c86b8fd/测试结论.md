# ReAct 上下文规划实测（2026-11-05）

结论：真实模型能够依据前序观察逐轮选择动作，但当前生产链还没有通过“稳定的 MCP 全流程＋可信最终判定”的验收。任务反思已送入模型，不等同于已获得自进化。此次未修改生产源码。

## 真实运行结果

本地执行器对照耗时 270.96 秒，12 次模型规划、12 个动作、3 次视觉观察。全部 12 次 Thought 的来源均为 model。实际阶段：YOLO 初检 1 次、区域提议 1 次、局部 YOLO 1 次、GLM 局部定位 5 次、目标身份分类 1 次。没有执行分割和测量。

内部裁决：insufficient_evidence、needs_review=true；交付层：tentative 秦皮，score=0.5946、review_required=false。0.5946 是当前 6:4 融合分数，不是已校准正确率。与龙胆参考不符，不能算识别成功。原有输出契约不一致再次暴露。最终 admission 模型无可用/有效结果，记录为 deterministic fallback；不能将这一环宣称为模型自主确认。

停止原因 override_exhausted，而非主动 finish 或时间耗尽。

## ReAct 和 Reflection 是否起作用

【已确认】模型在第 3 轮引用砂晶阳性观察，转查乳管；随后依据乳管阴性和强制场景缺口选择 scene_check，再改用局部提议、YOLO 重检、GLM 定位。定向定位给出 crop 后，模型选择 classify_target，身份不可判后继续换 ROI。不是每轮机械选第一项。

【已确认】第 8—12 次规划上下文带有 task_reflection。反思卡由程序根据动作收益生成，不是另一段模型自我反省；后续摘要仍主要是继续搜乳管，并未证明反思使策略更优。系统没有自动修改权重、判据或发布跨任务提示策略。

【不足】候选只有秦皮、桔梗，真正的针晶/龙胆未进入调查范围；反复搜索同一个已阴性的特征，缺少假设扩展。虽然换 ROI 属于有效动作变化，当前还缺少“为什么新区域值得再查”的可检验价值约束。两个无有效进展的连续停止建议覆盖最终触发 override_exhausted。

【不足】第 4 轮模型说“置信度足够”，下一轮又说“偏低”，说明自然语言理由并不是稳定、可验收的置信度协议。判断必须落到受信状态、证据资格和判据缺口。

【不足】整图无框、局部一度有 crop，并不意味着身份合格；分类无法判定后未开放分割/测量是本轮真实状态。不能为演示长度而绕过身份和 QA。

## MCP 阻塞定位

最初在线 MCP 运行仅规划 1 次，YOLO 操作尚未预约。其后由测试监督者主动终止，harness_stop.json 明确不是 Agent 的停止决定，不能写成 workflow_deadline 或成功结束。

独立禁止网络的重算探针：initialize 成功、注册表约 0.016 秒返回；recompute_tool 12 秒无返回。栈位于工作线程首次导入 detect_core → cv2 → numpy 的 native extension create_module。见 mcp_stack_probe/stack.log。原长运行未装抓栈器；同一根因适用于原运行是有力推断，不是原进程栈的直接证明。

以一次性启动包装将 cv2 放到服务主线程预加载后，同一禁止网络探针约 1.02 秒返回合法 ACTION_DENIED，证明冷导入位置与阻塞有关。此探针不消耗图像 API，不是修复后真实 MCP 识别测试。生产启动入口尚未修改。

## 后续实现顺序与验收

1. 在 MCP 服务接请求前主线程预热 native 依赖，或消除调度层为读取类别映射而导入 detect_core 的依赖；增加冷进程重算 watchdog 回归。验收需真实 MCP 完整跑通，不能只测 list_tools。
2. 修复已接受观察的状态回写：读取 action.args.feature_id 和 accepted/result；有效 absent 必须进入对应视野的已观察状态，失败保留 unknown。增加阴性后不再被 supporting 门反复要求的断言。
3. 给模型结构化 hypothesis/缺口/已排除范围/新动作预期增益，允许有依据地申请扩展候选；资格、预算、来源仍由程序校验。候选扩展不能读取参考答案。验证候选外真值和无目标样本。
4. 将 override 的次数护栏与问题是否发生有效变化结合，不能仅因换 ROI 清零，也不能将有信息增益的连续调查粗暴截断；保留总时间、调用和循环上限。
5. 统一内部 verdict、输出 top、review 标记和 admission 的状态来源。确定性降级必须显式标注，DecisionLLM 必须进入共享预算和截止。复核状态不得被交付层改写成 false。
6. 修复现有一项回归，再在分组独立样本上比较无反思/现反思/改进反思；以问题解决、错误结论、覆盖率、成本评价，不能以“有 reflection 字段”为通过。
