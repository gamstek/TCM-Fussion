## 目录名

`类型__对象__数量与单位__开始时间__目的`

例如 `实跑__龙胆__05图__20261109-1645__Agent补扫` 表示用龙胆的 5 张图做了一次 Agent 补扫测试。新任务名末尾追加 `-<8位十六进制短ID>`，用于同秒运行的隔离。

| 字段 | 填法 |
| --- | --- |
| 类型 | `实跑` 使用真实入口，`预检` 只准备并执行本地 doctor，`回放` 使用已录制工件，`评估` 统计一批输入。查看终态用 `interface_status.json`、`job.json` 或评估报告。 |
| 对象 | 人工登记的药材或测试集名。盲测使用 `S01` 等中性代号。没有明确对象时使用 `未标注`。 |
| 数量与单位 | 入口以通过校验的 manifest 为准，图数至少两位，如 `01图`、`05图`。回放用其来源的输入视野数。数据集评估按实际口径写图、样本或用例，数量来自摘要。 |
| 开始时间 | 新任务使用北京时间 UTC+8，格式 `YYYYMMDD-HHmmss`。历史分钟级或日期级记录只保留可核实的精度。 |
| 目的 | 写正在验证的功能，如 `候选审查`、`身份反思同图`。新入口标签为 1–16 个字符，使用中文、字母、数字或组间单个连字符。默认 `链路测试`。 |

`multi-view` 和兼容入口 `five-view` 自动生成名称。传入 `--subject S01 --purpose 链路验收` 可指定目录标签。盲测也应避免在输入路径和目的中写参考答案。旧脚本可沿用 `--name` 指定整个目录名。内部 `runs/fusion_<id>` 是运行及跨工件绑定，保留程序生成的标识。直接使用低层 `run --config` 时从该命令的输出获取工件路径。
