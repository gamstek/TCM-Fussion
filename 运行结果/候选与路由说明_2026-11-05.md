# 候选输入与路由门说明（2026-11-05）

回答两个容易混淆的问题：

1. 报告里的“五折 Top-1”表只是**摘要**，不是 Agent 的候选输入；
2. “CNN 概率特别大就不走 Agent”是 `routing` 门，本次没有启用，而且现有门只支持单视图。

## 1. 实际候选是每折 Top-3

两份配置都显式写了：

```json
"agent": {"candidate_policy": {"top_k": 3}}
```

`candidate_policy.candidates(a, kb, aliases, {"top_k": 3})` 会取**每一折的前 3 名**，映射到知识库 ID 后去重，作为 Agent 的候选兴趣集合。`a_prediction.json.fold_rankings` 保留完整榜单；报告里的“Top-1”只是每折第一名的紧凑展示，用来观察五折分歧。

实际并集：

| 样本 | 每折 Top-3 映射后并集 | 未映射项 |
|---|---|---|
| 龙胆 5 视野 | 龙胆、桔梗、麦芽、乌梅、秦皮、石膏、菟丝子、黄芪、苦参（9 个） | 党参联结乳管、木香木纤维、板蓝根木纤维、木香菊糖 |
| 知母 5 视野 | 知母、黄芪、甘草、G4、益母草、黄连、苦参、白头翁、艾叶（9 个） | 党参联结乳管 |

知母的 25 个“折×视野”组合 Top-1 全是知母；但候选集合仍然是每折 Top-3，所以 Agent 还能看到黄芪、G4 等低概率候选，规划器也据此写了“五折一致高置信指向知母，但仍需核验针晶”的判断。

## 2. 为什么知母 25/25 没有触发“跳过 Agent”

两份任务的 `routing.json` 都是：

```json
{"mode": "off", "recommend_skip": false, "skip": false, "reason": "legacy_path"}
```

原因有三层：

1. **配置没有写 `routing`**：`run_pipeline` 的 `route(a, None, ...)` 直接返回 `legacy_path`，门根本没参与。
2. **多视图没有 `ranking`**：现有 `routing_policy.route` 只读 `a["ranking"]`；多视图 A 的 `ranking=[]`，只有 `view_predictions`。即使配置 `routing`，也会返回 `invalid_or_unavailable_a`，不会跳过。
3. **现有门只支持单视图**：`shadow` 只记录建议、仍跑 Agent；`trial` 才真跳过；`validated` 需要已发布的风险门。三者都不是“直接确认药材”，`trial` 的结果是 A 暂定分类、B 与 Agent 未执行、仍需复核。

### 如果按“单视图门”逐视野算

用现有 `route` 对每个 `view_prediction`（视野平均值）套一个假设的 `trial` 门：`min_score=0.99, min_margin=0.90, buffer=0.0001`：

| 样本 | 逐视野结果 |
|---|---|
| 知母 | 5/5 视野 `heuristic_pass`（0.9969～0.9996，margin 0.9963～0.9993） |
| 龙胆 | 0/5 视野通过（0.639～0.9896，view_03 还是秦皮 0.685） |

所以你的直觉是对的：**知母的逐视野置信度确实足以过 0.99/0.90 的单视图门；龙胆过不了。** 但现有代码没有把这个“逐视野门”聚合成样品级门，多视图任务也不会用 `routing` 跳过。

## 3. 跳过 Agent 意味着什么

即使补上多视图门并跳过 Agent：

- 产出是 **A-only 暂定分类 + 需复核**，不是 confirmed；
- 不会执行 YOLO 检测、分割、测量，因此没有框、mask、微米长度；
- 对知母这种“A 很强但 B 仍需物理证据”的样本，会丢掉现在已经拿到的 IoU 0.96、80.64 μm 证据。

所以“高置信跳过 Agent”适合做**分诊/提速**，不适合替代“确认药材”。若目标是确认，仍需要 B 的物理证据；若是分诊，应明确标注 A-only、needs_review。

## 4. 建议

1. 在报告里把“Top-1 摘要”和“Top-3 候选输入”分开写，避免再误读。
2. 若要启用多视图跳过：新增样品级门，条件是**所有视野、所有折的 Top-1 一致且最低概率/最小 margin 过阈值**；返回 `A-only + needs_review`，并明确不产出 B 证据。
3. 若不想丢物理证据：不要把“跳过 Agent”当确认；把 A 的 25/25 作为**并列排序先验**（例如 0.4 并列时优先知母），仍保留人工复核。
4. 龙胆这类视野间分歧大的样本，继续走 Agent；门不应放行。
